# 采购方案样例（虚构案例）

## 0. 使用说明

- 本文件中的客户、供应商 A/B/C、参数、时间与价格机制**全部为虚构假设**，仅用于演示方案结构。
- 方案中的卡型、数量、网络与交付条件均为**示例假设**，不对应任何真实资源或在售容量。
- 价格一栏只写**计费机制**，不写具体金额；真实项目须由供应商正式报价并逐案核验。
- 本样例不构成报价、要约、供应承诺或合规意见。

---

## 1. 客户与场景（虚构）

**示例客户**：一家总部位于东南亚的视频生成 AI 公司（虚构，暂称 "Client S"），团队约数十人，产品为面向营销与影视的短视频生成工具。

**需求背景（假设）**：
- 正在训练下一代视频生成模型，需要 64 张 H100 级别 GPU 的单一训练集群。
- 计划使用 6 个月，前 4 个月以预训练为主，后 2 个月做微调与推理验证。
- 训练数据约数百 TB，主要存放在东南亚某对象存储；团队工程师分布在两个国家。
- 对数据驻留没有硬性要求，但要求训练任务可审计、集群稳定、故障恢复快。
- 预算量级已确认，但客户希望先看方案结构与风险，再谈价格。

## 2. 需求拆解（示例）

| 维度 | 需求（假设） | 备注 |
|---|---|---|
| 工作负载 | 视频生成模型预训练 + 微调 | 后续可能追加推理 |
| 精度 | BF16 为主，部分 FP8 实验 | 需要驱动与框架支持 |
| GPU 型号 | H100 级别（80GB） | 可接受同代同级替代，但需先做基准测试 |
| 规模 | 64 卡单集群（8 节点 × 8 卡） | 不接受跨集群拼接 |
| 互联 | 节点内 NVLink/ NVSwitch；节点间 InfiniBand 或高带宽 RoCE | 需提供实测带宽 |
| 存储 | 并行文件系统，容量 ≥ 数百 TB，高吞吐 | 需支持数据迁移 |
| 交付 | 合同后 2–4 周内可开始，允许分批上线 | 首批 32 卡，两周内补齐 |
| 时长 | 6 个月，可续约 | 是否锁定价格待谈 |
| 地点 | 东南亚优先；中国内地可作为备选但需评估跨境与合规 | 需客户确认数据路径 |
| 计费 | 按小时/按月，倾向长期承诺换取价格 | 价格机制待供应商报价 |
| 合规 | 需确认出口管制、数据跨境与客户行业要求 | 我方不下结论，仅列核查项 |

## 3. 候选方案对比（A/B/C 均为虚构）

| 维度 | 方案 A：新加坡托管集群 | 方案 B：马来西亚自建机房托管 | 方案 C：中国内地集群 + 跨境访问 |
|---|---|---|---|
| 位置 | 新加坡（假设） | 马来西亚柔佛（假设） | 中国内地某智算中心（假设） |
| 卡型 | H100 80GB（假设） | H100 80GB（假设） | H100 级别国产/进口混合（假设，待核验） |
| 规模 | 64 卡单集群 | 64 卡单集群，可扩至 128 | 64 卡单集群 |
| 网络 | IB 200G/400G（假设，待实测） | RoCE + IB 混合（假设） | IB（假设，跨域链路需评估） |
| 交付 | 2–3 周（假设） | 3–5 周（假设，含机柜与上架） | 2–4 周（假设） |
| 存储 | 托管并行存储，按需扩容 | 需自购或租用存储 | 本地并行存储，跨境回传需评估 |
| 价格机制 | 按小时/按月；长期承诺有折扣 | 包集群月付，含电与机柜；运维另计 | 按小时/包月；跨境链路与合规成本另计 |
| 主要风险 | 单点区域、价格较高、容量真实性待核验 | 交付周期较长、运维责任边界复杂、当地合规待确认 | 跨境延迟与数据路径、出口管制与合规不确定性 |
| 我方初评 | 交付与网络最匹配，价格偏高 | 成本可能最优，交付与运维风险需管理 | 成本与弹性有吸引力，合规前置条件最多 |

> 表中所有参数、周期与机制均为**假设**，仅用于展示对比方法；任何真实方案都必须以供应商书面材料与核验结果为准。

## 4. 推荐与理由

**推荐：方案 A 为首选，方案 B 为备选，方案 C 仅在客户接受跨境合规评估前置的前提下保留。**

理由：
1. **匹配度**：A 的交付周期与网络形态最接近客户 64 卡单集群、6 个月连续训练的需求。
2. **风险可控**：A 位于客户熟悉的区域，数据路径与运维响应更短，便于附加 SLA。
3. **可谈判性**：A 提供长期承诺折扣机制，适合 6 个月周期；B 的成本优势需要以更长的交付与运维投入换取。
4. **保留 C 的价值**：C 在单位成本与弹性上有潜力，但跨境数据路径与出口管制是硬约束，须先完成合规核查再讨论。

**推荐不等于承诺**：最终选择取决于核验结果、正式报价、SLA 条款与客户合规判断。

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 供应商容量真实性无法确认 | 交付延期 | 要求上架证明、监控截图、第三方验证；分阶段放量 |
| 网络实测带宽低于标称 | 训练效率下降 | 合同前做基准测试；写入 SLA 与验收条款 |
| 交付分批导致训练中断 | 项目延期 | 首批 32 卡先跑小规模验证，第二批上线后迁移 |
| 跨境数据路径不确定 | 合规风险 | 只做路径梳理与书面披露，由客户与其法律顾问判断 |
| 价格机制不透明 | 预算失控 | 要求逐项报价与计费口径；锁定价格浮动条款 |
| 单区域故障 | 训练中断 | 要求备份与恢复方案；关键检查点异地备份 |
