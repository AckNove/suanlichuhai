# 中国算力国际化服务商 · 公司介绍

**英文暂定名：China Compute Globalization Services（CCGS）**
**一句话定位：连接中国可商业化算力资源与全球 AI 计算需求的专业服务商。**

## 一、我们是谁

我们是一家总部拟设于中国的算力国际化服务商，暂定名 CCGS。我们不做硬件买卖，也不运营机房，而是站在算力供需两侧之间，提供需求分析、资源寻源、供应商核验、方案比较与商务协调服务。

我们用两种语言工作，也同时理解两种商业语境：一方面熟悉中国智算中心、GPU 云与算力运营商的资源结构与商务习惯；另一方面理解海外 AI 企业在采购算力时的技术标准、合规关切与决策流程。

**公司主体目前处于设立阶段。** 本材料为草案，用于内部对齐与早期沟通准备；在 CEO 书面批准前，不得作为正式对外文件发送。

## 二、我们解决什么问题

算力跨境采购的难点，从来不是"哪里有卡"，而是以下四件事同时成立：

1. **需求说不清**——客户知道自己要训模型，但说不清需要什么卡型、多少卡、什么互联、什么交付周期。
2. **供给看不透**——供应商名单很多，但谁是真正的资源方、谁只是中间层，外部客户很难判断。
3. **方案比不了**——不同地区的报价、计费单位、网络条件、合规限制不一样，直接比单价会得出错误结论。
4. **交易接不上**——语言、时区、合同习惯、付款路径不一致，导致有意向却落不了地。

我们的工作，就是把上述四个问题逐一拆开、核实、翻译成双方都能执行的商务语言。

## 三、我们做什么：供需两侧的两套服务

### 需求侧（买方）：算力采购顾问

需求分析 → 算力规格定义 → 全球资源寻源 → 供应商核验 → 采购方案比较 → 风险识别 → 商务协调 → 持续采购管理。

我们交付的不是一张报价单，而是一份可比较、可追问、可落地的采购判断：每个候选方案来自哪里、依据是什么、风险在哪里、还缺什么信息。

### 供给侧（卖方）：海外市场拓展服务

海外市场研究 → 潜在客户发现 → 合格采购需求筛选 → 商机引入 → 商务协调 → 持续渠道合作。

我们帮助中国算力供应商把"有资源"转化为"有合格客户"：在把需求带到供应商面前之前，先完成筛选，不匹配的需求提前拿掉，减少双方的时间损耗。

## 四、三条业务线（按优先级）

| 优先级 | 业务线 | 内容 | 当前阶段 |
|---|---|---|---|
| 第一 | 中国智算供给出海 | 帮助中国智算中心、GPU 云、算力运营商开发海外及跨境客户 | 服务模式已定义，正在建立首批候选资源库 |
| 第二 | 外数中算与跨境 AI 计算 | 研究海外数据、模型推理、AI 工作负载进入中国境内处理的商业机会与合规路径 | 仅研究与合规路径梳理；未经专业法律审核，不对任何客户承诺合法、合规或可执行 |
| 第三 | 全球算力采购与资源配置 | 建立全球供应商数据库，为全球客户提供采购、寻源、方案比较与持续采购管理 | 数据库建设中；目标市场全球，不预先限定区域 |

三条线共用同一套方法：先核实，再匹配，后协调。任何一条线都不跳过核验环节。

## 五、我们不是什么

清楚边界，比夸大能力更能建立信任。以下事情我们**不做**：

- **不自营机房**：我们不拥有、不运营 GPU 数据中心。
- **不购买 GPU 库存**：我们不囤卡、不转售硬件。
- **不做 Token 工厂或模型 API 零售**：我们不包装模型能力对外售卖。
- **不托管客户采购资金**：在条件允许时，我们尽量促成客户与实际算力供应商直接签约、直接结算。
- **不规避出口管制**：我们不参与、不协助任何规避出口管制或未获授权芯片交易的安排。
- **不提供法律意见，也不宣称"已合规"**：合规结论只能由具备资质的专业机构出具，我们提供的是事实梳理与路径说明。
- **不虚构**：不虚报资源规模、客户名单、成交案例、合作伙伴或政府背书。

## 六、合作方式

1. **初次沟通（约 30 分钟）**：了解需求或资源情况，判断是否值得继续。
2. **需求/资源梳理**：形成书面概要，明确已知项、未知项与关键假设。
3. **方案与核验**：在可获得的信息范围内提供候选方案或客户线索，并说明核验状态。
4. **商务协调**：在双方有意向的前提下，协调对接、会议与合同前的商务事项。
5. **长期合作**：按项目制、成功介绍或长期渠道合作等方式，逐案书面约定。

收费采用 success-based 模式，具体口径按服务范围、成交规模、交易风险与工作量逐案商议，并在书面文件中确认；首轮沟通不涉及报价。
