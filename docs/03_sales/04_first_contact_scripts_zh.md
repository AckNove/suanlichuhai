# 首次联系话术（中英双语手册 · 中文版）

## 使用规则（先读）

1. **首轮不谈费率**：不出现佣金、返点、抽成、分成比例。对方追问时，用「合作方式与费用在确认具体项目后逐案书面约定」带过。
2. **每条不超过 150 词**：手机两屏内读完。宁可少说，不要废话。
3. **一个钩子、一个 CTA**：钩子必须具体（来自对方公开信息或行业事实），CTA 必须低门槛（回一句话 / 30 分钟电话 / 转发给对的人）。
4. **不群发**：每条至少改一处与对方直接相关的细节，否则不发。
5. 所有 `[方括号]` 均为待填占位符；发送前逐项替换并检查。
6. 本手册为草案，未经 CEO 批准不得对外发送。

## 场景 1：供应商冷邮件

**适用**：中国智算中心、GPU 云、算力运营商（含新港主体）。
**目标**：拿到一次 30 分钟资源访谈，不是拿报价单。

### 版本 1A：资源方直发版

**主题**：关于 [对方公司] [具体观察] 的一点合作想法

[对方姓名] 您好，

我是 [我方姓名]，在 CCGS（中国算力国际化服务商，暂定名）负责海外需求对接。我们在为海外 AI 公司寻找可用的训练与推理算力，看到 [对方公司] 在 [具体观察]，想确认是否在你们的可售范围内。

我们不要求独家，也不在首轮谈费用。想先用 30 分钟了解你们的型号、可售数量、机房位置和交付周期；如果有匹配的海外需求，我们再谈怎么合作。

方便的话，下周哪个时间段合适？或者您回一句「可以聊聊」，我发三段时间供选。

顺祝工作顺利
[我方姓名] | CCGS | [待 CEO 填写]

> 禁用：不写「大量现货」「资源充足」「保证有单」「行业最低」。

### 版本 1B：生态 / 平台合作版

**主题**：为 [对方公司] 对接海外算力需求（非独家、无前期费用）

[对方姓名] 您好，

我是 CCGS 的 [我方姓名]。我们做的是中国算力资源的海外需求对接：先把需求筛到「可谈」的程度，再带到资源方这里，减少无效询价。

看到 [对方公司] 的 [具体观察]，判断可能有交集。我们不做独家、不锁渠道、不收前期费用，首轮只想了解你们的资源结构和海外服务意愿。

30 分钟线上沟通即可，方便的话请回一个时间段。

[我方姓名] | CCGS | [待 CEO 填写]

## 场景 3：客户冷邮件

**适用**：海外 AI 企业（训练、微调、推理、渲染、仿真）。
**目标**：拿到一次需求澄清通话，不推销具体资源。

**主题**：关于 [对方公司] 的 [训练/推理] 算力采购

[对方姓名] 您好，

我是 CCGS 的 [我方姓名]。我们替海外 AI 团队做算力采购顾问：把需求规格化，做全球寻源，核验供应商，再给可比较的方案与风险。我们不卖卡，也不在客户价格上加价。

看到 [具体观察]，猜你们可能在扩 [训练/推理] 容量。我们可以在首次 30 分钟通话后，免费给一份初步资源匹配说明（2–3 个方向 + 风险点），不构成报价。

如果现在不是时候，回一句「暂不需要」即可；如果方便，请告知下周可通话时间。

[我方姓名] | CCGS | [待 CEO 填写]

### 版本 3B：痛点切入版

**主题**：跨境算力采购：把「能不能买」变成「值不值得买」

[对方姓名] 您好，

我们是买方顾问，做三件事：定义规格、全球寻源、核验供应商，并把风险写在方案里。不承诺最低价，也不下合规结论——这两件事没人能替你的法务做。

愿意用 30 分钟聊聊你们当前的采购方式吗？结束后给一份免费的初步匹配说明。

[我方姓名] | CCGS | [待 CEO 填写]

## 禁用词清单（发送前逐条对照）

| 禁用词 / 表达 | 为什么禁用 | 替换说法 |
|---|---|---|
| 保证 / 包 / 一定能 | 无法兑现的承诺 | 「我们会尽量」「在信息可核验范围内」 |
| 最低价 / 最便宜 / 全网最优 | 不掌握全市场价格，且易引发比价纠纷 | 「可比较的方案」「价格机制差异」 |
| 官方授权 / 独家代理 / 总代 | 无授权即虚构，法律风险高 | 「资源方」「合作方」「待核验」 |
| 行业第一 / 顶级 / 领先 | 未证实表述 | 删除，或改为具体事实 |
| 大量现货 / 资源充足 / 随时可交付 | 未核验的容量表述 | 「可售数量待供应商书面确认」 |
| 已合规 / 包合规 / 合法无忧 | 我们不提供法律意见 | 「合规路径待专业机构确认」 |
| 政府背书 / 国资背景 / 关系硬 | 不可核实且高风险 | 删除 |
| 内部渠道 / 特殊关系 / 有路子 | 暗示规避管制 | 「公开渠道」「合规路径」 |
| 佣金 / 返点 / 抽成 / 分成 X% | 首轮不谈费率；写死比例违反项目规则 | 「成功后书面约定、个案商议」 |
| 某某大厂都在用 / 客户包括 [大厂] | 无授权且无法核实 | 「服务过的客户类型」（如有真实案例） |
| 稳赚 / 零风险 / 绝对安全 | 误导性表述 | 「主要风险与缓解措施」 |
| 免费（无限定） | 易被理解为全部服务免费 | 「首次沟通后提供初步匹配说明（免费）」 |
| 100% / 全网 / 所有 | 绝对化表述 | 具体范围 + 条件 |
