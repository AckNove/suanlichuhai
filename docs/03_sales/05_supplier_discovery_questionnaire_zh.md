# 供应商需求访谈表（30 问 · 可直接照读）

## 使用说明

- **时长**：建议 30–45 分钟。前 5 分钟说明来意，中间 30 分钟提问，最后 5 分钟确认下一步。
- **提问方式**：按顺序问，允许跳过对方明确不方便回答的项；追问用「能具体说一下吗」「有没有材料可以看」。
- **不诱导**：不要问「你们肯定有很多卡吧」这类引导性问题；不要替对方说出数字。
- **记录原话**：关键数字（型号、张数、周期、价格机制）记录对方原话，不做美化转述。
- **不承诺**：访谈中不承诺客户数量、不承诺成交、不谈费率、不承诺采购量。
- **状态标注**：每项回答必须标注 `已确认（有证据）` / `对方口述` / `待确认` / `不适用`。
- **访谈后 24 小时内**：整理纪要发给对方确认；同步更新供应商状态（LEAD → RESEARCHED → NEEDS_VERIFICATION）。

## 记录规则（访谈中与访谈后都必须遵守）

1. **四态标注**：`已确认（有证据）` / `对方口述` / `待确认` / `不适用`。没有证据的口述，不得写成已确认。
2. **证据分级**：HIGH（官方文件/可核验后台）/ MEDIUM（截图/第三方转述）/ LOW（口头描述）/ UNVERIFIED（无来源）。
3. **原话优先**：数字与承诺记录原话，转述时标注「转述」。
4. **不补全**：对方没说的信息留空，不根据常识推断填写。
5. **不美化**：不使用「资源充足」「实力雄厚」等评价性表述，只记录事实。
6. **不越权**：访谈中不报价、不承诺采购、不签任何文件、不收任何费用。
