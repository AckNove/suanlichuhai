# 中国算力国际化服务商（CCGS）

**连接中国可商业化算力资源与全球 AI 计算需求的专业服务商**

---

## 问题

跨境算力采购的难点不在"有没有卡"，而在于：需求说不清、供给看不透、方案比不了、交易接不上。买方不知道谁是真正的资源方，卖方不知道谁是真正有预算的客户，双方都缺一层可核验的翻译与协调。

## 我们的服务

**对买方（海外 AI 企业）**：需求分析 → 算力规格定义 → 全球寻源 → 供应商核验 → 方案比较 → 风险识别 → 商务协调 → 持续采购管理。

**对卖方（中国算力供应商）**：海外市场研究 → 客户开发 → 合格需求筛选 → 商机引入 → 商务协调 → 持续渠道合作。

我们交付的是可比较、可追问、可落地的判断，不是一张报价单。

## 三条业务线

| 优先级 | 业务线 | 一句话 |
|---|---|---|
| 1 | 中国智算供给出海 | 帮中国智算中心、GPU 云、算力运营商开发海外及跨境客户 |
| 2 | 外数中算与跨境 AI 计算 | 研究海外数据与 AI 工作负载入境处理的商业与合规路径（仅研究，不承诺合法合规） |
| 3 | 全球算力采购与资源配置 | 为全球客户提供 GPU 采购、寻源、方案比较与持续采购管理 |

## 目标客户

- **需求侧**：训练、微调、推理、渲染、仿真等真实工作负载的海外 AI 企业。
- **供给侧**：中国智算中心、GPU 云服务商、算力运营商，以及新加坡、香港等地的华人算力主体。

## 差异化

1. **买方立场**：不在客户价格上加价，尽量促成客户与资源方直接签约、直接结算。
2. **先核验后推荐**：未通过核验的资源不进入方案；信息不足就标注不足。
3. **双语双市场**：同时理解中国供给结构与海外采购习惯。
4. **负责任的边界**：不承诺最低价，不下合规结论，不参与规避出口管制的安排。

## 我们不是什么

不自营机房 · 不购买 GPU 库存 · 不做 Token 工厂或模型 API 零售 · 不托管客户资金 · 不规避出口管制 · 不提供法律意见或宣称"已合规"。

- 已核验合格供给：0；已核验合格需求：0；已签介绍协议：0；真实成交：0。

## 合作方式

首次沟通（约 30 分钟）→ 书面需求/资源摘要 → 寻源与核验 → 方案比较与风险说明 → 商务协调（如双方决定推进）→ 长期合作按项目制、成功介绍或渠道方式逐案书面约定。

收费采用 success-based 模式，具体口径逐案商议并在书面文件中确认；首轮沟通不涉及报价。
