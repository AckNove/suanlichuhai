# 商务材料索引（CCGS / 中国算力国际化项目）

本目录存放可复用的中英双语商务工具，共 10 组、20 个文件，另有本索引。中文版用于中国境内沟通与内部培训，英文版用于海外客户、海外华人算力商及新加坡/香港主体；两版事实一致、表述独立，不逐字直译。

## 使用规则

1. **状态**：全部为草案 v1.0，公司主体设立中，未经 CEO 批准不得外发。
2. **真实性**：不虚构公司规模、客户、案例、合作伙伴、资质、代理权、政府背书、真实报价与联系人；无法确认写「待确认」。
3. **收费口径**：首轮不谈费率，不出现具体百分比；如被追问，统一表述为 success-based, agreed case by case in writing。
4. **合规口径**：只做风险识别与路径梳理，不提供法律意见，不宣称「已合规」。
5. **占位符**：联系方式、注册信息、地址一律以 `[待 CEO 填写]` / `[To be completed by CEO]` 保留，使用前替换。
6. **双向材料**：供应商与客户各用一套说明，不得交叉使用；不得向客户披露撮合、差价或抽成逻辑。
7. **留痕**：对外发送前记录对象、版本、日期与批准人。

- **供应商线**：02 介绍 → 05 访谈 → 09 核验 → 08 方案（内部）→ 10 跟进

## 维护规则

- 版本号与日期写入每份文件顶部；修改后保留旧版备查。
- 事实、条款或口径变化（主体、收费、合规、业务线）须由 CEO 确认后统一更新，避免版本不一致。
- 对外材料引用本目录内容时，只引用经批准的事实句，不引用内部评分、核验记录与决策逻辑。
