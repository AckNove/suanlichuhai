# 客户服务介绍：从算力需求到可决策的采购方案

## 一、我们在你的采购中扮演什么角色

我们不是 GPU 卖家，也不是把报价层层加码的中间商。我们是**买方侧的算力采购顾问**：帮你把需求定义清楚，把全球可选资源找出来，把供应商核验一遍，再把可比较的方案和风险摆在桌面上，由你决定买谁的、怎么买。

我们尽量促成你与实际算力供应商直接签约、直接结算。我们的价值在于过程，而不是在价格上加一层。

## 二、第一步：把"我要算力"变成可采购的规格

大多数算力采购出问题，是因为需求没定义清楚。我们按以下维度与你逐项确认：

| 维度 | 需要确认的问题 |
|---|---|
| 工作负载 | 训练 / 微调 / 推理 / 渲染 / 仿真？是否有混合负载？ |
| 模型与规模 | 模型类型、参数规模、并行策略、显存需求 |
| 卡型 | 偏好型号及理由；是否接受替代型号 |
| 数量与时长 | 需要多少卡、连续使用多久、是否有阶段性波峰 |
| 集群与互联 | 单集群规模、节点内/节点间互联要求、是否需要 RDMA 类网络 |
| 存储与数据 | 存储容量与吞吐、训练数据量、数据上传/下载方式 |
| 地点与数据驻留 | 是否限定国家/地区、是否有数据本地化要求 |
| 合规与准入 | 行业限制、出口管制敏感度、数据跨境要求 |
| 启动时间 | 何时必须开始、可接受的交付周期 |
| 预算量级 | 预算区间或成本目标（用于筛选，不用于压价） |

确认后，我们输出一份**需求规格摘要**：哪些已确认、哪些是假设、哪些必须由你方内部确认。后续所有寻源与比较都以此为准。

## 三、第二步：全球寻源

我们不预设地区。寻源范围包括中国境内智算中心、GPU 云，以及新加坡、香港、东南亚、中东、欧洲、北美等地可服务的资源主体（具体范围随项目而定）。

寻源方式：供应商数据库 + 公开信息检索 + 行业渠道 + 直接接触。每一条候选资源都标注来源与获取时间，并区分"公开信息"与"已直接确认"。

**我们不承诺一定能找到满足全部条件的资源。** 如果市场上确实没有，我们会明确告诉你"没有"，而不是拿一个勉强凑合的方案充数。

## 四、第三步：供应商核验

在把任何供应商放进方案之前，我们按五个维度核验：

1. **主体与授权**：营业执照/注册信息、签约主体、资源所有权或合法转售权、出口管制声明。
2. **资源真实性**：机房位置、上架证明、监控/后台截图、第三方可验证信息、可核实的客户案例。
3. **容量与型号**：型号清单、可售数量、已占用情况、扩容计划、故障率。
4. **交付与网络**：交付周期、SLA、带宽、互联方式、存储方案、运维响应。
5. **商务与合规**：价格机制、计费单位、付款条件、发票、数据驻留、跨境条款。

核验结果分为 `VERIFIED` / `PARTIALLY VERIFIED` / `REJECTED` / `INSUFFICIENT INFO` 四档，并逐项附证据与未决问题。**未通过核验的资源不会进入推荐方案**；信息不足的会明确标注，而不是默认合格。

## 五、第四步：对比方案与风险

我们提供的方案对比至少包含以下列：位置、卡型与规模、网络与存储、交付周期、价格机制（不是单一总价）、付款条件、供应稳定性、合规限制、主要风险、证据等级、待确认事项。

三个原则：

- **不把不同计费口径直接比单价**（按小时、包年、包集群、按 token 的不可直接比较）。
- **把未知项写出来**：没有证据的地方标"待确认"，不替供应商补全。
- **给出推荐及理由**：推荐哪个、为什么、什么情况下推荐会改变。

## 六、我们不承诺什么

为了避免误解，以下事项我们明确不承诺：

1. **不承诺最低价。** 我们提供的是可比较、可核验的方案，不是价格保证。市场变化、汇率、供应紧张都会影响最终价格。
2. **不承诺合规结论。** 我们不提供法律意见，也不会说"这个方案已合规"。涉及出口管制、数据跨境、行业准入的判断，须由你的法务或具备资质的专业机构出具意见；我们提供事实梳理与待确认清单。
3. **不承诺资源一定可得。** 可售数量与交付周期以供应商最终书面确认为准。
4. **不承诺成交时间。** 交付、上架、网络打通的时间受多方影响。
5. **不替你做最终决策。** 我们给建议，签字的是你。

## 七、首次沟通你可以得到什么

首次沟通（约 30–45 分钟）后，你会得到一份**免费的初步资源匹配说明**，包含：

- 你的需求中已明确与仍缺失的关键项；
- 2–3 个可能匹配的资源方向（区域/资源类型层面，非正式报价）；
- 每个方向的主要限制与风险；
- 下一步建议：继续深化、补充信息，或当前市场条件下不建议推进。

说明基于公开信息与初步渠道判断，**不构成正式报价、不构成供应承诺**；深度寻源与核验属于付费服务范围，具体合作方式与收费在书面文件中约定。

## 八、合作流程

初次沟通 → 需求规格摘要 → 寻源与核验 → 方案对比与风险说明 → 商务协调（如你决定推进）→ 签约与交付跟进（在约定范围内）→ 持续采购管理（可选）。

在条件允许时，我们建议由你与实际算力供应商直接签约、直接结算；我们不托管你的采购资金。
