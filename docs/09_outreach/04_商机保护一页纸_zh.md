# 非独家渠道合作与商机保护要点（一页纸）

## 一、我们是谁

专注中国算力出海的商务服务团队（公司主体设立中，由 [CEO 姓名] 发起）。我们研究海外与跨境算力需求，把公开线索筛成可核验的需求，再与可交付的资源方对接。**我们不拥有机房、不囤卡、不转售算力、不托管资金。**

## 二、合作方式（非独家）

| 项 | 约定 |
|---|---|
| 排他性 | **非独家**。贵司可同时与任何第三方合作，我方不要求独家代理、不限制贵司其他渠道 |
| 我方职责 | 海外需求研究与筛选、需求方资格核验、商务引荐、会议与材料协调、交易推进协调（至合同前阶段） |
| 贵司职责 | 提供真实、可核验的资源信息；对引荐需求及时反馈（建议 5 个工作日内）；条件允许时与需求方直接签约结算 |
| 资金 | 我方**不托管**客户或供应商资金；不由我方代收代付 |
| 价格 | 我方**不加价**、不赚差价；贵司报价直接给到需求方 |

## 三、商机登记与保护

1. **登记**：具体项目由我方以书面形式（邮件即可）向贵司登记，载明需求方名称/行业、需求内容、预计规模、时间窗。
2. **确认**：贵司在收到登记后 **5 个工作日内**书面确认（确认即生效；逾期无异议视为确认）。
3. **保护期**：自确认日起 **12 个月**。保护期内，该登记商机由我方协调；贵司不绕过我方与该需求方直接成交或通过第三方成交。
4. **保护范围**：仅限已登记的具体商机，不覆盖贵司的其他客户与渠道。
5. **保护终止**：保护期届满、或贵司书面放弃、或需求方明确终止，保护自动结束。

## 四、费用（本轮不涉及）

- 首轮沟通**不讨论费率**，不产生任何费用；
- 出现具体项目时，双方逐案签署书面文件，约定收费模式、计算基数、支付节点与退费条件；
- 若同一项目供需双方均向我方付费，我方**事前书面披露**并取得双方同意；
- 任何口头表述不构成收费依据。

## 五、保密与数据

- 双方对合作中获知的非公开信息保密（价格、客户、容量、合同条款）；
- 我方仅在需求方书面同意后，向需求方披露贵司名称与资源概况；
- 跨境数据处理遵循适用法律与贵司合规要求，我方不作合规承诺、不规避出口管制。

## 六、边界与退出

- 本要点不构成合同、代理授权或任何排他承诺；正式合作以双方签署的书面协议为准；
- 任何一方可提前 10 个工作日书面通知终止合作意向；
- 终止不影响已登记商机在保护期内的约定，也不影响已签署协议的履行。
