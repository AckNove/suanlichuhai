# 合规口径与禁止事项（对外沟通红线）

## 一、可以说的（事实性）

1. 我们做中国算力出海的**商务服务**：需求研究、筛选、引荐、协调。
2. 公司**主体设立中**，由 CEO 本人发起（如选口径 A）。
3. 我方**不拥有机房、不囤卡、不转售算力、不托管资金、不加价**。
4. 登甲官网公开信息（可引用并注明「据贵司官网」）：DengCloud 三大业务、出海方案页、2026-11-16 与中国电信万卡集群签约新闻、腾讯云战略合作新闻。
5. 我方**尚无成交**：零核验供应商、零签约、零回款——被问到时如实回答。

## 二、不能说的（无授权/未核实）

| 禁止表述 | 原因 |
|---|---|
| 「我们已经服务过 XX 客户」「有 XX 家海外客户」 | 虚构客户 |
| 「登甲是我们的合作伙伴/已签约供应商」 | 尚未核验、未签约 |
| 「我们能保证给你带来 X 个客户 / X 张卡的需求」 | 承诺不可控结果 |
| 「10% / 8% 佣金」「行业标准费率是……」 | 费率逐案商议、不得写死、首轮不报价 |
| 「政府背书 / 国企合作 / 信通院认证（除引用对方官网自述外）」 | 资质未核 |
| 「数据出境没问题 / 合规我们搞定」 | 不出合规结论，需律师 |
| 「可以帮你规避出口管制」 | 绝对红线，且违法 |
| 「先把需求方名字告诉你」 | 未书面登记前不得泄露 |
| 「可以代收代付」 | 我方不托管资金 |

## 三、身份与署名纪律

- 只用 CEO 本人真实姓名与真实联系方式；
- 不得使用未注册公司名义签约、报价、承诺；
- 不得冒充其他公司、中介或客户；
- 邮件签名不得含虚假职务/资质。

## 四、需求侧信息保护

- 需求方名称、预算、联系人：**书面商机登记确认前不向供应商披露**；
- 公开研究得到的信息可以描述行业与区域，但不点名、不暗示；
- 对方提供的报价、容量、客户名单：仅用于本项目内部评估，不转发第三方。

## 五、跨境与出口管制

- 不参与任何规避出口管制的安排（不以「第三国转口」「测试用途」等名义规避）；
- 涉及跨境数据处理的场景，只做风险识别与路径梳理，明确告知「需专业法律审核」；
- 不对客户承诺合规结论；不在材料中写「合法合规可执行」。

## 六、发送与留痕

- **所有对外发送只能由 CEO 执行**；AI/团队只准备材料，不代发；
- 发送后 24 小时内登记 project_activities，7 日内补登对方回复；
- 对外材料必须标注「草案，未经 CEO 批准不得外发」直到 CEO 签字确认版本。
