# 渠道合作条款清单（Channel Partnership Term Sheet）

> 项目：中国算力国际化项目（CCGS）· 中国算力出海
> 版本：v1.0 ｜ 日期：2026-11-16 ｜ 状态：内部草案，待 CEO 审批
> 性质声明：**本文为商业条款设计，不构成法律意见；正式合同须律师审核。** 本文不是合同、不是要约，不得直接签署或对外作为合同文本使用。
> 适用模式：`docs/02_commercial/COOPERATION_MODELS.md` 模式 B（供应商非独家渠道合作），模式 D（联合市场拓展）可参照并增补联合投入条款。

## 0. 使用说明

1. 本文用于与**供应商（资源提供方）**谈非独家渠道合作时的条款框架；谈成后交律师起草正式协议。
2. **当事人**：甲方＝供应商/资源方（委托方）；乙方＝渠道方（CCGS，主体设立中）。
3. **性质**：非独家、非代理、非雇佣、非合资。乙方以自身名义开展市场活动，不代甲方签约、不收款、不承诺资源。
4. 方括号【 】内为逐案填写项；佣金比例/金额一律逐案由 CEO 批准后填入，本文不预设数字。
5. 与「成功介绍协议」的区别：介绍协议以**单笔已登记商机**为对象；渠道协议以**持续渠道关系**为对象，覆盖多商机、品牌使用与客户归属。两者可组合（见第 12 节）。

## 1. 合作性质与定位

| 条款 | 商务要点 |
|------|----------|
| 非独家 | 甲方可与其他渠道/直销并行；乙方可代理其他供应商；双方均无排他义务 |
| 非代理 | 乙方无权以甲方名义签署合同、报价、收款、承诺交付或作出任何约束甲方的意思表示 |
| 非雇佣 | 乙方为独立主体，自担成本、税务与人员责任 |
| 客户合同 | 客户与甲方直接签约、直接结算；乙方不经手资金、不加价 |
| 服务内容 | 海外市场研究、客户开发、合格需求筛选、商机引入、商务协调、持续渠道维护 |
| 不承诺结果 | 乙方不保证带来商机数量、成交或收入；甲方不保证资源可用性 |

## 2. 商机登记

| 编号 | 条款 | 商务要点 |
|------|------|----------|
| 2.1 | 登记方式 | 乙方按附件《商机登记表》书面提交（邮件/指定系统），含客户名称、国家地区、需求规格、预算量级、时间窗、联系人角色、信息来源 |
| 2.2 | 确认时限 | 甲方 **5 个工作日**内书面确认或提出异议（附已有客户/在谈证据）；逾期未回复的处理 **【建议视为确认，待律师确认】** |
| 2.3 | 去重规则 | 同一客户以**首次有效登记**为准；甲方能证明登记前已存在书面在谈记录的，该客户不纳入；双方对登记状态有争议的，先协商，协商不成按第 9 条 |
| 2.4 | 排除客户 | 甲方在协议附件列明「既有客户/既有渠道清单」，清单内客户不适用本协议（清单可季度更新，新增须提前书面通知） |
| 2.5 | 登记有效期 | 登记后 **【12/18 个月】**内未成交的，登记自动失效；可书面申请续期一次 |
| 2.6 | 记录留痕 | 每次登记、确认、异议、变更均存档；双方可要求查阅与自身相关的记录 |

---

## 3. 保护期

1. 自甲方书面确认登记之日起算，默认 **12 个月**；经双方书面同意可延长 **6 个月**（最多一次）。
2. 保护期内，甲方就该登记客户与登记需求：不得绕过乙方直接成交（详见第 7 条）；不得同时委托其他渠道方就该同一商机竞争（商机级排他，可选）。
3. 保护期届满未成交的，登记失效；乙方可重新登记，但甲方有权拒绝（须书面说明理由）。
4. 保护期不限制甲方与客户就**非登记需求**（不同规格、不同区域、不同业务）的直接合作。

## 4. 佣金计算与结算

| 条款 | 商务要点 |
|------|----------|
| 计费基础 | 默认「首年合同应付总额」（含算力费/服务费/承诺最低消费，不含税费与代垫）；或按「甲方净收入」 **【逐案选择】** |
| 佣金比例/金额 | **【逐案填写，CEO 批准】**；可设阶梯（规模越大比例越低），但具体数字不在本文预设 |
| 计算示例 | 仅写公式：佣金 = 计费基础 × 比例（比例逐案审批），不写示例费率 |
| 结算周期 | 成交后 **30 日**内结算；或按甲方回款进度分期（**可选**），最迟成交后 **12 个月**付清；长期合作可按**季度**对账结算 |
| 支付前提 | 甲方书面确认成交并提供金额证明；乙方提供合规票据（主体设立后） |
| 对账 | 每季度双方对账一次；差异 **15 个工作日**内解决；逾期未解决按第 9 条 |
| 币种与汇率 | 计价币种 **【USD/CNY】**；汇率基准按 `PRICING_AND_FEE_FRAMEWORK.md` 第 8 节 |
| 税费 | 各自承担其应纳税费；跨境预提税按适用法律与税收协定处理（须税务顾问确认） |
| 续约/扩容 | 是否计佣、如何计佣 **【可选条款，逐案约定】**；未约定的默认不计 |
| 退款/争议 | 合同被撤销且非乙方原因的，按比例返还已收佣金；重复计算的，多退少补 |

**佣金纪律**：不向客户加价；不向客户收取未披露费用；不通过关联方变相收费；双付费须事前披露并取得双方书面同意。

## 5. 双方品牌使用

| 条款 | 商务要点 |
|------|----------|
| 有限许可 | 双方仅在**书面批准**范围内使用对方名称、Logo、商标，用于「合作方」事实性表述 |
| 禁止暗示 | 不得暗示独家代理、官方授权、合资、背书或保证；不得注册对方商标/域名 |
| 材料审批 | 对外宣传材料、网站、演示文稿使用对方品牌前须书面审批；审批不构成内容背书 |
| 权属 | 商标、品牌、内容归原权利人；许可终止即失效 |
| 终止后 | 停止使用对方品牌；已印材料在 **30 日**内处理完毕 |
| 违约 | 超范围使用须立即停止并消除影响；造成损失的按第 10 条 |

---

## 6. 客户归属

1. **合同关系**：客户与甲方直接签约，客户合同项下权利义务归甲乙双方；乙方不是合同当事人。
2. **客户数据**：客户资料由甲方作为合同相对方持有；乙方仅保留开展渠道工作所必需的最小信息。
3. **归属判定**：以「首次有效登记 + 保护期内成交」判定渠道贡献；同一客户多商机的，按各商机分别判定。
4. **禁止转移**：乙方不得将客户引导至甲方竞争对手或关联方以规避佣金；不得私自与客户签署替代协议。
5. **存量客户**：附件清单内的既有客户不归属乙方；清单外客户按登记规则处理。
6. **客户自主**：客户有权拒绝乙方参与、要求更换对接人；甲方应尊重客户选择，但不因此免除已触发佣金。

## 7. 冲突解决（渠道/直销/多渠道）

| 冲突类型 | 处理规则 |
|----------|----------|
| 甲方直销 vs 渠道 | 登记在先且保护期内的，视为渠道商机；甲方能证明在登记前已书面在谈的除外 |
| 多渠道同一客户 | 以首次有效登记为准；后登记方可申请「协作分成」，须三方书面同意 |
| 同一客户不同需求 | 按商机分别判定，不互相占用 |
| 甲方关联方介入 | 视为甲方行为，适用反跳单条款 |
| 乙方重复登记 | 首次登记有效，重复登记自动失效并书面说明 |
| 争议升级 | 双方 **30 日**内协商；不成按第 9 条争议解决 |
| 临时冲突 | 争议期间暂停该商机的对外报价与签约（如可行），避免损失扩大 |

**反跳单（直接/间接）**：
- 直接：保护期内甲方绕过乙方与登记客户就登记需求成交 → 视为成交，按第 4 条支付佣金。
- 间接：通过关联方、第三方、变更签约主体、拆分合同、补充协议等方式实质成交 → 合并计算，按约支付。
- 核查：乙方可每年不超过 **2 次**要求甲方提供相关成交摘要（脱敏）；甲方 **15 个工作日**内提供。
- 违约：逾期支付按 **【日万分之 X，待律师定】** 计息；恶意绕开的可约定违约金 **【待定】**。

## 8. 合规与出口管制声明

> 本节为条款设计，**不构成法律意见，也不构成任何合规承诺**。

1. **各自合规**：双方各自遵守适用的出口管制、经济制裁、反腐败、反商业贿赂、数据保护、外汇管理法律。
2. **不规避**：双方不得通过本合作规避出口管制、制裁、许可要求或最终用户/最终用途限制。
3. **用途核查**：甲方应向乙方提供（在合法且必要范围内）资源出口/跨境服务的合规状态；乙方不得协助任何规避行为。
4. **敏感场景**：涉及跨境数据、受限芯片/设备、受制裁主体或地区的，双方应暂停并寻求专业法律意见；协议可中止/终止且不构成违约。
5. **不承诺**：乙方**不承诺**任何交易合法、合规或可获得政府批准；甲方亦不就乙方行为作出合规背书。
6. **违规处理**：一方发现违规风险的，应立即书面通知对方；对方未在 **15 日**内纠正的，可终止协议。
7. **记录**：合规沟通、筛查结果、终止决定须留痕。

## 9. 期限、终止与存量商机

| 条款 | 商务要点 |
|------|----------|
| 生效 | 双方签署之日；乙方主体设立前为「待生效」，签署安排由律师确认 |
| 初始期限 | **【24 个月】**；期满未终止的自动续 **12 个月**（可选） |
| 正常终止 | 任一方提前 **60 日**书面通知 |
| 立即终止 | 重大违约、欺诈、违法违规、制裁/出口管制风险、破产、品牌滥用 |
| 终止后结算 | 已成交商机的佣金按约支付；进行中工作按已完成部分结算 |
| 存量商机 | 终止前已登记且处于保护期的商机，终止后 **12 个月**内成交仍按约支付佣金 |
| 资料交接 | 乙方移交客户对接记录（合法范围内）；甲方支付未结佣金 |
| 品牌停用 | 终止后 **30 日**内停止使用对方品牌 |

## 10. 责任限制

1. 乙方不对甲方的资源可用性、交付、质量、合规作任何担保；甲方不对乙方的市场开发结果作任何承诺。
2. 除故意或重大过失外，任一方对另一方的累计赔偿责任不超过**该方在本协议下已支付/已收取的佣金总额**（或逐案约定上限）。
3. 双方互不承担间接损失、利润损失、商誉损失。
4. 客户与甲方之间的合同争议由双方自行解决，与乙方无关（乙方故意误导除外）。

---

## 11. 保密与数据

1. 保密范围：商机信息、客户名单、价格、合同条款、渠道策略。
2. 保密期限：协议终止后 **3 年**；商业秘密可更长。
3. 个人信息：仅共享业务联系人信息，确保来源合法、最小必要；接收方按适用法律处理（GDPR/PDPA 等）。
4. 数据跨境：如需跨境传输，须取得必要授权并完成适用法律评估；不得擅自传输。
5. 泄露通知：发现泄露 **24 小时**内通知对方并采取补救措施。

## 12. 与其它协议的关系

| 场景 | 建议 |
|------|------|
| 先签渠道协议、后出现具体商机 | 渠道协议 + 每笔商机登记（附件）；无须逐笔签介绍协议 |
| 先有具体商机、再谈合作 | 直接签《成功介绍协议》（`INTRODUCTION_AGREEMENT_TERM_SHEET.md`） |
| 联合投入市场活动 | 渠道协议 + 模式 D 补充条款（预算、分工、成果归属、退出） |
| 客户侧服务 | 另签《采购顾问服务条款清单》（`PROCUREMENT_ADVISORY_TERM_SHEET.md`），并做双付费披露 |
| 冲突 | 同一交易同时适用多份协议的，以**更具体**的协议为准；佣金不重复计算 |

## 13. 待律师确认项（清单）

1. 乙方主体设立中的签署安排与生效条件。
2. 「逾期未确认视为确认」的可执行性。
3. 佣金计费基础（首年应付总额 vs 净收入）的定义与边界。
4. 阶梯佣金、续约/扩容计佣的可执行性与反垄断风险。
5. 商机级排他条款是否构成限制竞争。
6. 反跳单条款、举证责任、违约金上限。
7. 关联方与签约主体变更的认定。
8. 客户归属规则与客户数据权属。
9. 品牌许可的范围、审批流程与终止后处理。
10. 出口管制/制裁中止权的表述与触发条件。
11. 多渠道路径冲突的分成机制。
12. 跨境税务、预提税、常设机构风险。
13. 争议解决（仲裁/诉讼、地点、语言、适用法律）。
14. 终止后存量商机的佣金期限。
15. 电子签署与通知条款。
