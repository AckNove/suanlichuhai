# 产品与服务目录 · 双套产品体系

> 版本：v1.0　｜　日期：2026-11-16　｜　状态：内部草案，待 CEO 审批，不得外发
> 适用范围：对外报价前的内部定义、交付物模板依据、与 6 类费用的映射关系。
> 基线：`docs/00_project_audit/PROJECT_BRIEF.md` 第 3、4 节。

---

## 0. 使用规则（先读）

1. **供需两侧是两套产品**，话术、交付物、商务方案不得混用。任何材料不得把「赚信息差/收撮合费/抽成」讲给双边客户。
2. 本目录中所有价格表述均为「**定价逻辑**」，不写金额、不写费率、不写档位。定价一律逐案商议，由 CEO 审批。
3. 每个产品都写「不包含什么」，这是边界，也是免责与预期管理工具。
4. 交付以**书面交付物签收**为准；口头建议不计为交付。
5. 周期为**规划区间**（假设），不是承诺 SLA；实际周期以 CEO 与客户书面确认为准。

## 1. 需求方产品套件（买方视角：帮客户买对算力）

### D-01 需求分析（Need Analysis）

| 项 | 内容 |
|----|------|
| 服务内容 | 与客户澄清业务场景（训练/推理/微调/数据处理）、模型规模、并发与吞吐、精度要求、可接受延迟、预算区间、时间窗、数据驻留要求 |
| 交付物 | 《需求说明书 v1》：结构化字段表 + 未澄清项清单 + 优先级排序 |
| 周期 | 3–10 个工作日（假设），取决于客户配合度 |
| 依赖 | 客户提供业务信息；必要时签署 NDA；我方不作技术选型担保 |
| 定价逻辑 | 按工作量与信息复杂度商议；若后续进入寻源或成功费项目，可抵扣 |
| 不包含 | 不替代客户内部技术评估；不做模型效果评测；不承诺「这个需求一定能被满足」 |

### D-02 算力规格定义（Spec Definition）

| 项 | 内容 |
|----|------|
| 服务内容 | 把业务需求翻译为可采购规格：卡型与代际、显存、互联（IB/RoCE）、存储与吞吐、网络出口、机房位置、交付形态（裸金属/虚拟实例/集群）、计费粒度 |
| 交付物 | 《采购规格书》：必备项 / 可选项 / 排除项 三档 |
| 周期 | 2–5 个工作日（假设） |
| 依赖 | D-01 完成；客户技术负责人参与确认 |
| 定价逻辑 | 含在 D-01 或单独计；逐案商议 |
| 不包含 | 不承诺特定卡型可长期稳定获得（受出口管制与市场供给影响）；不做硬件采购代理 |

### D-03 全球寻源（Global Sourcing）

| 项 | 内容 |
|----|------|
| 服务内容 | 在可用范围内检索并接触候选供应商，形成候选池；按规格书做初筛 |
| 交付物 | 《候选供应商清单》：来源、位置、宣称规格、核验状态（UNVERIFIED/VERIFIED）、待澄清项 |
| 周期 | 5–20 个工作日（假设） |
| 依赖 | 规格书确认；CEO 授权接触（外联权在 CEO）；无主体阶段仅做公开信息层 |
| 定价逻辑 | 项目寻源服务费，按范围与难度逐案商议 |
| 不包含 | 不承诺覆盖「全球全部供应商」；不接触未经授权的名单；不代客户谈判价格 |

### D-04 供应商核验（Supplier Verification）

| 项 | 内容 |
|----|------|
| 服务内容 | 对候选供应商做四层核验：主体真实性（工商/注册信息）、容量真实性（可售 SKU 与数量）、交付能力（机房、网络、交付周期）、合作意愿（是否接受我方服务模式） |
| 交付物 | 《核验报告》：核验项 × 结论（通过/不通过/待确认）、证据来源与获取时间、信任度分级 |
| 周期 | 5–15 个工作日（假设） |
| 依赖 | 供应商配合提供证明材料；必要时视频/实地查验（需 CEO 批准与费用） |
| 定价逻辑 | 按核验深度讨论；逐案商议 |
| 不包含 | 不做财务审计；不提供法律尽调；不对供应商履约做担保 |

### D-05 采购方案比较（Option Comparison）

| 项 | 内容 |
|----|------|
| 服务内容 | 对 2–5 个候选方案做多维比较：规格匹配度、交付周期、价格结构（不代报底价，只做结构对比）、合规风险、合同条款差异、退出成本 |
| 交付物 | 《方案比较矩阵》+ 推荐意见（含推荐理由与反对理由） |
| 周期 | 3–7 个工作日（假设） |
| 依赖 | 至少 2 个已核验方案；客户确认比较维度权重 |
| 定价逻辑 | 按方案数量与复杂度商议 |
| 不包含 | 不替客户做最终决策；不对价格做「最低价」承诺；不披露其他客户的商务条款 |

### D-06 风险识别（Risk Identification）

| 项 | 内容 |
|----|------|
| 服务内容 | 识别交易风险：出口管制、数据出境、制裁名单、外汇与支付路径、履约与 SLA、汇率与账期、供应商集中度 |
| 交付物 | 《风险清单》：风险项、等级、触发信号、建议缓释、需律师/专业机构确认项 |
| 周期 | 3–5 个工作日（假设） |
| 依赖 | 需要客户披露使用场景与数据类别 |
| 定价逻辑 | 按场景复杂度商议 |
| 不包含 | **不提供法律意见**，不宣称「已合规」；不替代客户或供应商的合规责任 |

### D-07 商务协调（Commercial Coordination）

| 项 | 内容 |
|----|------|
| 服务内容 | 组织双方会议、准备议程与一页对照、传递澄清问题、跟踪待办、记录结论；推进合同前条款对齐 |
| 交付物 | 会议纪要、问题台账、条款对齐表（非合同文本） |
| 周期 | 随项目推进，通常 2–8 周（假设） |
| 依赖 | 双方愿意被协调；CEO 参与关键会议 |
| 定价逻辑 | 交易协调费，按协调强度与周期商议 |
| 不包含 | 不代签合同、不代收代付、不承诺成交、不介入双方商业条件决策 |

### D-08 持续采购管理（Ongoing Procurement Management）

| 项 | 内容 |
|----|------|
| 服务内容 | 对长期采购做季度级管理：供应商绩效跟踪、续约与扩容提醒、价格与条款复盘、替代方案储备、风险预警 |
| 交付物 | 季度采购报告 + 供应商记分卡 + 风险预警清单 |
| 周期 | 按季/按年（假设，合同约定） |
| 依赖 | 客户授权信息共享；供应商配合数据提供 |
| 定价逻辑 | 长期采购管理费，按管理规模与服务层级商议 |
| 不包含 | 不承担客户内部采购审批责任；不承诺成本一定下降；不托管采购资金 |

## 2. 供给方产品套件（卖方视角：帮中国算力找到海外客户）

### S-01 海外市场研究（Overseas Market Research）

| 项 | 内容 |
|----|------|
| 服务内容 | 针对指定区域/客群做需求结构研究：算力缺口类型、价格带公开信息、主要玩家、进入壁垒、合规约束、典型采购路径 |
| 交付物 | 《市场研究简报》：结论 + 证据来源 + 不确定性标注 + 可执行建议 |
| 周期 | 10–20 个工作日（假设） |
| 依赖 | 供给方明确目标区域与自身规格边界 |
| 定价逻辑 | 供应商海外市场拓展服务费，按区域数量与研究深度商议 |
| 不包含 | 不承诺「研究覆盖所有市场」；不做投资建议；公开信息无法核实的部分明确标注 |

### S-02 客户开发（Customer Development）

| 项 | 内容 |
|----|------|
| 服务内容 | 基于市场研究，定位目标客户画像与决策链，形成候选名单与接触路径建议；准备开口材料（CEO 批准后使用） |
| 交付物 | 《目标客户名单》：画像、需求信号、来源、优先级、建议接触方式（不写未核实联系方式） |
| 周期 | 10–30 个工作日（假设） |
| 依赖 | **外联权在 CEO**；无主体阶段不承诺接触 |
| 定价逻辑 | 按目标数量与行业难度商议 |
| 不包含 | 不代发邮件/私信；不承诺接触成功率；不购买联系人数据（须 CEO 批准） |

### S-03 合格需求筛选（Qualified Demand Screening）

| 项 | 内容 |
|----|------|
| 服务内容 | 对海外需求做资格筛查：规格可匹配性、预算量级、时间窗、决策人、数据驻留、合规可行性；不匹配的提前排除并说明原因 |
| 交付物 | 《需求筛选报告》：每条需求的资格结论 + 排除原因 + 需澄清项 |
| 周期 | 每批 5–10 个工作日（假设） |
| 依赖 | 需求信息来源合法；与客户接触须 CEO 授权 |
| 定价逻辑 | 含在 S-02 或单独计，逐案商议 |
| 不包含 | 不把公开线索升级为「已核实需求」；不承诺筛出的需求一定能成交 |

### S-04 商机引入（Opportunity Introduction）

| 项 | 内容 |
|----|------|
| 服务内容 | 在合格供给与合格需求匹配成立后，由 CEO 正式介绍双方；准备一页对照（规格、缺口、建议问法）并进行介绍后跟进 |
| 交付物 | 介绍记录 + 一页对照 + 跟进台账 |
| 周期 | 介绍后跟进 2–12 周（假设） |
| 依赖 | 介绍协议已覆盖该单（或同步签署）；CEO 本人执行介绍；双方同意被介绍 |
| 定价逻辑 | 成功介绍费，触发条件为双方签约或首笔付款（以较早者为准）；比例逐案商议，**不得引用历史 10%/8% 作为现行费率** |
| 不包含 | 不保证对方采购；不介入对方定价谈判；不承诺介绍次数 |

### S-05 商务协调（Commercial Coordination，供给侧）

| 项 | 内容 |
|----|------|
| 服务内容 | 协调供给方准备商务材料：公司介绍、规格表、SLA 草案要点、交付计划、验收标准；协助双方对齐合同前条款 |
| 交付物 | 商务材料包 + 条款对齐表 + 待办台账 |
| 周期 | 2–6 周（假设） |
| 依赖 | 供给方提供真实材料；材料对外前须 CEO 批准 |
| 定价逻辑 | 交易协调费或含在成功费内，逐案商议 |
| 不包含 | 不代写合同、不代签、不提供法律意见；不美化无法核实的容量 |

### S-06 持续渠道合作（Ongoing Channel Partnership）

| 项 | 内容 |
|----|------|
| 服务内容 | 长期为供给方维护海外渠道：持续需求发现、季度需求画像更新、重点客户关系跟进、市场变化提示 |
| 交付物 | 季度渠道报告 + 需求画像更新 + 商机台账 |
| 周期 | 按季/按年（假设） |
| 依赖 | 双方签署长期合作协议；供给方保持规格与价格信息更新 |
| 定价逻辑 | 渠道合作费/年费或按单成功费组合，逐案商议 |
| 不包含 | 不承诺年度商机数量；不承诺独家代理（除非另有书面约定并经 CEO 批准） |

## 3. 产品组合（内部设计，不作对外套餐名使用）

| 组合 | 组成 | 适用客户 | 付费方 |
|------|------|----------|--------|
| 组合 A：买方全程顾问 | D-01 → D-07 | 有明确采购需求但缺跨境经验的海外客户 | 需求方 |
| 组合 B：供给方出海启动 | S-01 → S-02 → S-04 | 想试水海外但无团队的中国供给方 | 供给方 |
| 组合 C：单点核验 | D-04 单项 | 已有候选、需第三方核验的客户 | 需求方 |
| 组合 D：长期管理 | D-08 或 S-06 | 已有稳定采购/渠道关系的客户 | 需求方或供给方 |

> 组合只是内部报价构件。对外必须按客户具体问题裁剪，不推销「套餐」。

## 4. 服务边界总则（所有产品共用）

| 我方提供 | 我方不提供 |
|----------|------------|
| 研究与结构化分析 | 法律意见、税务意见、审计意见 |

| 合规风险提示与律师转介 | 「已合规」结论、规避管制的方案 |

## 6. 交付与签收标准

1. 每份交付物须有：版本号、日期、编制人、适用客户（脱敏编号）、来源标注、待确认项。
2. 交付即触发客户确认（邮件或书面签收）；未确认的交付不算完成。
3. 交付物中不得出现未经核实的容量、价格、联系人、合作意向。
4. 客户数据按 `data/private/` 规则处理，不入公开仓库。
