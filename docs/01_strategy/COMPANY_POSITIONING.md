## 1. 一句话定位

**我们是一家「服务商」，不是「供应商」。** 我们连接中国可商业化的智算供给与全球 AI 计算需求，卖的是**研究、匹配、核验、商务协调与持续采购管理**，不卖卡、不卖机时、不托管资金。

| 项 | 内容 | 性质 |
|----|------|------|
| 中文名 | 中国算力国际化项目（中国算力出海） | 事实（内部项目名） |
| 英文名 | China Compute Globalization Services（CCGS） | 判断（暂定，未注册，待 CEO 确认） |
| 工商主体 | 尚未设立 | 事实（主体设立中，不得暗示具备签约与收款能力） |
| 总部 | 中国（具体城市待 CEO 定） | 待确认 |
| 负责人 | CEO Arthur；AI 项目总负责人（内部建设） | 事实 |
| 阶段 | 0 → 1 验证期：内部建设完成，商业闭环未跑通 | 事实 |

> 口径提醒：对外任何材料不得自称「平台已上线」「已合作」「已成交」「已合规」。当前可对外成立的表述只有「在做中国算力与海外需求之间的研究与对接服务」这一层，且需 CEO 批准后使用。

## 2. 我们是什么 / 不是什么

### 2.1 我们是什么（可对内部确认的定位）

| 维度 | 定位 | 说明 |
|------|------|------|
| 产业角色 | 跨境算力交易的**专业服务商 / 中间服务层** | 赚服务费，不赚差价 |
| 核心能力 | 需求结构化、供给核验、匹配解释、商务协调 | 能力型，不是资产型 |
| 收入性质 | 服务费 / 顾问费 / 介绍费 / 协调费 / 管理费 | 6 类费用，逐案商议 |
| 资产形态 | 数据、证据链、供需图谱、流程与话术 | 轻资产，可积累 |
| 组织形态 | AI 原生：AI 做标准化研究/处理/执行，人做判断/信任/谈判/法律/决策 | 见 `BUSINESS_OPERATING_MANUAL.md` |

### 2.2 我们不是什么（红线，任何材料不得越过）

| 不做 | 原因 |
|------|------|
| 自营机房 / 自建 GPU 集群 | 重资产，与 0→1 验证期资金结构不符 |
| 自购 GPU 库存 / 囤卡 | 库存风险与价格波动不可承受 |
| Token 工厂 / 模型 API 零售 | 会与供给侧客户变成竞争关系，破坏中立性 |
| 未获授权的芯片或算力交易 | 合规红线 |
| 违规规避出口管制 | 合规红线，且会摧毁全部长期价值 |
| 客户资金托管 / 代收代付 | 无牌照、无主体、无能力承担资金风险 |
| 在需方价格上加价 | 损害双边信任，且与「服务费」定位冲突 |
| 未经批准的跨境数据处理 | 合规红线 |
| 提供法律意见 / 宣称「已合规」 | 仅做公开信息提示与律师转介 |

> **判断**：以上九条在 0→1 阶段是「护城河」而非「限制」。因为不自营、不囤货，我方才能同时服务多家供给方而不被当成竞争者。

## 3. 使命 / 愿景 / 长期价值

| 项 | 表述 | 性质 |
|----|------|------|
| 使命 | 让可交付的中国算力与真实的全球 AI 计算需求更高效、更可验证地相遇 | 判断 |
| 愿景 | 成为跨境算力交易中「最可被核验」的服务层：每一份推荐都能说清理由、来源与风险边界 | 判断 |
| 长期价值 | 用结构化的供需图谱、证据链与标准流程，降低跨境算力交易的信任成本与试错成本 | 判断 |

**价值观（4 条，可对照考核）**

1. **可核验优先于好听**：任何结论必须有来源与时间；无法确认写「待确认」。
2. **双边披露优先于短期成交**：向供需双方收费时必须事前书面披露，不做隐藏利益。
3. **边界优先于机会**：合规存疑的单，宁可不做，不做「先接了再想」。
4. **克制表达**：不承诺结果、不夸大规模、不编造案例。

## 4. 三条业务主线

### 4.1 主线总表

| 编号 | 主线 | 优先级 | 当前状态 | 我们的角色 | 本期允许动作 |
|------|------|--------|----------|------------|--------------|
| A | 中国智算供给出海 | **P1（第一）** | 内部建设完成，0 成交 | 供给方出海服务 + 需求方寻源服务 | 研究、建档、核验准备、待 CEO 外联 |
| B | 外数中算与跨境 AI 计算 | **P2（第二）** | 仅研究；无法律意见 | 研究与合规路径梳理 | **只做研究与合规路径**，不对外承诺 |
| C | 全球算力采购与资源配置 | **P3（第三）** | 未启动 | 全球寻源与采购管理服务 | 逐步建供应商库，不对外承诺全球覆盖 |

### 4.2 A 线：中国智算供给出海（第一优先级）

| 项 | 内容 |
|----|------|
| 定义 | 服务中国智算中心、GPU 云服务商、算力运营商，帮助其开发海外/跨境客户 |
| 我方做什么 | 海外市场研究 → 潜在客户发现 → 需求分析 → GPU 资源寻源 → 供应商核验 → 需求与算力匹配 → 商务引荐 → 交易协调 → 项目跟进 |
| 供给方得到 | 合格海外需求被介绍上门；不匹配的单提前被拿掉；规格差距被说清 |
| 需求方得到 | 按规格筛过的可交付短名单；为什么配或不配；还需澄清什么 |
| 不做什么 | 不代签、不代收、不承诺成交、不承诺价格更低 |
| 为什么先做 A | 判断：中国侧供给相对可核验、可触达；需求侧虽是我方最大缺口，但 A 线的服务产物（匹配解释）在两侧都能验证 |

### 4.3 B 线：外数中算与跨境 AI 计算（第二优先级，仅研究与合规路径）

| 项 | 内容 |
|----|------|
| 定义 | 研究海外数据、模型推理、AI 工作负载进入中国境内处理的商业机会 |
| 本期边界 | **只做研究与合规路径梳理**；未经专业法律审核前，不得对外承诺合法、合规或可执行 |
| 必须逐案研究 | 客户国家/地区、数据来源地、数据进入中国路径、计算地点、数据类型（个人信息/重要数据/一般数据）、处理方式、结果交付方式、技术出口/跨境数据传输/许可、客户是否愿意使用境内算力 |
| 禁止 | 对外宣称可做；把「研究结论」当「法律意见」；在无律师意见前报任何跨境方案 |
| 升级路径 | 任何 B 线个案进入 `CROSS_BORDER_RISK_WORKFLOW.md` 筛查 → 律师确认 → CEO 决策 |

### 4.4 C 线：全球算力采购与资源配置（第三优先级）

| 项 | 内容 |
|----|------|
| 定义 | 逐步建立全球供应商数据库，为客户提供 GPU 采购、寻源、方案比较、持续采购管理 |
| 目标市场 | 全球，不预先限定东南亚（历史资料中的「东南亚优先」仅为研究观察，不作为承诺） |
| 本期动作 | 只做供应商信息结构化与来源标注；不接触、不报价、不承诺覆盖哪些国家 |
| 与 A 的关系 | C 是 A 的镜像能力：A 卖中国供给给海外，C 帮全球客户在全球找供给。共享同一套供应商核验与匹配方法 |

### 4.5 三线关系（判断）

A 是现金流主线；B 是期权（Option），在律师意见前只保留研究能力；C 是能力沉淀方向，用来把「匹配方法」产品化。**任何时点若资源冲突，按 A > B > C 分配。**
