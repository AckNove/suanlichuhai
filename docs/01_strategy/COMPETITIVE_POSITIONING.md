# 竞争定位 · 服务而非库存

> 版本：v1.0　｜　日期：2026-11-16　｜　状态：内部草案，待 CEO 审批，不得外发
> 适用范围：市场判断、销售异议应对、壁垒建设规划。
> 基线：`docs/00_project_audit/PROJECT_BRIEF.md`。本文涉及的竞品信息为**公开层观察与判断**，非尽调结论；不点名评价具体公司的经营优劣。

---

## 1. 竞争定位一句话

**在「有算力的人」和「要算力的人」之间，做那个既不持有库存、也不与任何一方争利、且每一句推荐都能被核验的服务层。**

一句话差异：**咨询公司给报告，中介给关系，云厂商给产品，我们给「可核验的匹配与可执行的下一步」。**

---

## 2. 竞争格局：五类替代方案

| 类别 | 典型形态 | 他们怎么赚钱 | 客户为什么选他们 | 结构性问题 |
|------|----------|--------------|------------------|------------|
| ① 公有云直销 | 头部云厂商销售体系、区域云 | 卖自己的资源，按用量计价 | 品牌、合规背书、开票与支持体系完整 | 只卖自家资源，跨云中立性不足 |
| ② GPU 云 / 算力运营商 | 按小时/按月零售的 GPU 平台、算力运营方 | 卖自家或聚合的算力，加价或抽成 | 即时开通、自助、价格透明 | 既是裁判又是选手；企业级跨境定制与合规澄清弱 |
| ③ 传统贸易 / 中介 | 数据中心转介、IDC 中介、贸易商、个人经纪人 | 佣金、差价、介绍费 | 有人情网络，决策链熟悉 | 方法不书面化、证据链弱、责任边界模糊 |
| ④ 咨询公司 | 战略/技术咨询、投行顾问 | 按项目收咨询费 | 方法论、报告质量、品牌信任 | 通常止步于报告，不介入交易执行 |
| ⑤ 跨境数据服务商 | 跨境数据合规、数据托管、跨境云服务 | 合规服务费 + 云资源 | 合规专业性强 | 主要解决数据侧，不解决算力供给匹配 |

## 3. 逐类对比：我们的优势与劣势（诚实版）

### 3.1 vs 公有云直销（①）

| 我方相对优势 | 我方相对劣势 |
|--------------|--------------|
| 中立：可比较多个供给方，不只推一家 | 无品牌、无合规资质、无开票能力（主体未设立） |
| 能做非标规格与跨境定制需求 | 无自有资源，交付依赖第三方，可控性低 |
| 提供「为什么配/不配」的解释 | 无法提供 SLA 与售后保障体系 |
| 可在需求侧不绑定单一云 | 价格上无优势，客户可直接找云厂商拿更低价格 |

**应对**：不打「比云便宜」，打「跨供给方的中立核验 + 跨境非标需求的落地支持」。客户已经在用某家云时，定位为补充而非替代。

### 3.2 vs GPU 云 / 算力运营商（②）

| 我方相对优势 | 我方相对劣势 |
|--------------|--------------|
| 不自营、不囤卡，不承担库存，不做价格对手 | 无库存意味着「客户要立刻上量」时我们无法直接交付 |
| 可服务多家供给方，不被单一资源绑定 | 需要供给方配合才能核验，响应速度受制于人 |
| 专注跨境企业单与合规澄清 | 自助平台体验、即时性、透明定价远不如对方 |

**应对**：避开「零售小时卡」这个战场。对方做标准化零售，我们做非标跨境企业单的核验与协调。若客户需求本质是标准零售，直接建议其用平台，不硬接。

### 3.3 vs 传统贸易 / 中介（③）

| 我方相对优势 | 我方相对劣势 |
|--------------|--------------|
| 方法书面化：档案、核验、匹配理由、证据链 | 没有人情网络与历史关系积累 |
| 责任边界清晰：不托管资金、不加价、不代签 | 决策速度与灵活度不如个人中介 |
| 可被审计、可复盘 | 中介常能给出「更活」的方案（含灰色操作，但那是红线） |

**应对**：不与之比谁关系硬，比「可核验、可追责、可长期合作」。

### 3.4 vs 咨询公司（④）

| 我方相对优势 | 我方相对劣势 |
|--------------|--------------|
| 做到执行层：核验、介绍、协调、跟进 | 品牌、资质、案例、团队规模全面落后 |
| 收费结构更贴交易结果 | 报告深度与方法论沉淀不足 |
| 更懂中国供给侧的实际情况（相对海外咨询） | 缺乏行业研究品牌与公信力 |

**应对**：定位为「咨询公司不做的那一段执行」。也可以考虑与咨询公司形成转介关系，而不是正面竞争。

### 3.5 vs 跨境数据服务商（⑤）

| 我方相对优势 | 我方相对劣势 |
|--------------|--------------|
| 聚焦算力供需匹配，而非数据合规本身 | 数据合规专业能力远不如对方 |
| 可作为对方方案中的「算力选型与核验」环节 | 无资质、无律师团队 |

**应对**：把对方视为**潜在互补方**而非竞争对手；涉及数据出境的 B 线业务，必须引入专业方。

## 4. 竞争定位坐标

```
                定制化 / 深度介入
                        ▲
                        │
        咨询公司 ●       │       ● 我们（目标位）
                        │
    ────────────────────┼────────────────────►
   不持有资产            │            持有资产
                        │
        传统中介 ●       │   ● GPU 云 / 算力运营商
                        │   ● 公有云直销
                        ▼
                标准化 / 轻介入
```

**判断**：我们的空位是「**深度介入 + 不持有资产**」。这个位置天然缺规模效应，但天然有中立性。0→1 阶段应放大中立性与证据链，而不是假装有规模。

## 5. 竞争壁垒设想（当前都不存在，属于建设目标）

| 壁垒 | 内容 | 当前状态 | 建设路径 | 可验证标准 |
|------|------|----------|----------|------------|
| B1 数据资产 | 结构化的供给/需求档案库，字段统一、来源可溯 | 有 18+9 条未核验线索 | 按字段标准建档、持续去重与更新 | 档案完整率、来源覆盖率 |
| B2 证据链 | 每条关键信息有来源 URL、时间、信任度、待确认项 | 规则已定，覆盖不全 | 建档强制字段 + 抽检机制 | 抽检合格率 100% |
| B3 供需图谱 | 区域 × 卡型 × 负载 × 合规约束的多维映射 | 无 | 匹配记录沉淀 + 定期结构化 | 可回答「某区域某卡型谁可能供」 |
| B4 流程标准化 | SOP、状态机、审批矩阵、交付物模板 | 文档已完成，未执行 | 跑通一轮并修订 | 端到端一次完整流程 |
| B5 案例与口碑 | 脱敏案例库 | 0 | 首单后沉淀 | ≥1 个可对外脱敏案例 |

**判断**：B1–B4 是**可以在 6 个月内靠纪律建成的**；B5 必须等真实成交。因此对外叙事不能把「未来壁垒」当「现有优势」。

## 6. 我们的四条真实短板（不得对外掩饰，内部必须承认）

| 短板 | 具体表现 | 影响 | 缓解 |
|------|----------|------|------|
| 无案例 | 一手成交访谈 0、成交 0 | 客户第一反应是「你做过吗」 | 用方法与交付物证明；承认在建立首批案例 |
| 无主体 | 未设立公司，无法签约/开票/收款 | 链条在「介绍」后断裂 | 优先解决主体（见 `COMPANY_SETUP_CHECKLIST.md`） |
| 无库存 | 无法立刻承诺容量与上架时间 | 客户要快时接不住 | 明确定位为服务与核验，不承接即时交付 |
| 无品牌 | 无知名度、无背书 | 冷启动获客成本高 | 依赖 CEO 个人网络与渠道伙伴 |

## 7. 竞争策略（本期）

1. **不做正面对抗**：不与公有云/GPU 云拼价格、拼即时性、拼规模。
2. **做窄而深**：先做「跨境企业级非标算力的核验与协调」这一条缝。
3. **把替代方案当筛选器**：客户若本质需要标准零售，直接建议其用平台，保留关系，等其出现非标需求。
4. **补位而非夺位**：与咨询公司、律所、跨境数据服务商形成转介，不自建其能力。
5. **用证据链建立第一层信任**：无案例时，「敢于写清不确定项」本身就是差异化。

## 附录 B　竞争情景推演

| 情景 | 触发条件（假设） | 对我的影响 | 预设应对 |
|------|------------------|------------|----------|
| S1 公有云降价 | 头部云厂商在目标区域大幅下调 GPU 价格 | 需求方更倾向直接采购，顾问价值被压缩 | 转向「多云/多区域比价 + 合规与交付风险」；不与价格战正面竞争 |
| S2 头部中介进场 | 出现有资本、有案例的撮合平台 | 我方先发劣势放大 | 收缩到 1–2 个细分客群，做深证据链与交付质量 |
| S3 政策收紧 | 出口管制或数据跨境规则趋严 | 跨境交易窗口收窄，B 线受阻 | A 线优先、B 线仅研究；强化合规筛查作为差异化能力 |
| S4 供给过剩 | 国内智算中心上架率不足，供应商急于出海 | 供给方更愿意付费，但也更易跳单 | 用「合格需求筛选」而非「承诺订单」定价，避免对赌 |
| S5 需求方自建 | 大客户自建采购团队 | 顾问需求下降 | 服务中小客户与长尾需求，提供持续采购管理 |

**判断规则**：情景推演不预测概率；每季度复核一次触发条件是否出现。

## 附录 C　定位话术对照表

| 场景 | 不建议的说法 | 建议的说法 |
|------|--------------|------------|
| 客户问「你们有什么资源」 | 「我们有很多机房资源」 | 「我们不持有资源，我们做的是需求定义、全球寻源与供应商核验」 |
| 客户问「你们比 cloud 便宜多少」 | 「能便宜 30%」 | 「是否更便宜取决于规格、区域与交付方式；我们先做需求分析再比较」 |
| 供应商问「你能给我带多少客户」 | 「我们客户很多」 | 「我们有合格需求筛选机制，只把符合你能力与合规要求的需求引给你」 |
| 客户问「你们和中介有什么区别」 | 「我们更专业」 | 「中介卖信息，我们交付可核验的判断与对比；我们不以成交为唯一收费条件」 |
| 渠道问「分佣怎么算」 | 「行业惯例 10%」 | 「逐案商议，事前书面确认；历史内部锚已不适用」 |
| 被问「做过哪些案例」 | 编造或含糊 | 「首批案例建立中，可以介绍我们的方法与核验标准」 |
