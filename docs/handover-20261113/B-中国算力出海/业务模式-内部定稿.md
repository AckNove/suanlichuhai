## 1. 一句话

我们做中国侧智算供给与海外（及跨境）需求之间的**信息撮合与匹配解释**：把可核的供需线索结构化，写清为什么配得上或配不上，列出还要澄清的问题，由 CEO 本人做商务验证与签约跟进。谈成后收取介绍费；若只做研究与匹配、暂不牵线，则收项目顾问费。

## 2. 做什么 / 不做什么

| 做 | 不做 |
|----|------|
| 发现并建档：国内可交付的智算供给、海外或跨境需求 | 自营机房、自营 GPU 集群、自己卖卡 |
| 规则 + 人工匹配，必须写清匹配与不匹配原因 | 成为 Token 工厂，或自营模型 API 零售 |
| 输出澄清清单（规格、区域、网络、数据驻留、合规提示） | 芯片灰市、绕出口管制的渠道 |
| 协助准备开口材料；敏感联系人/报价/合同只进 B/99 | 擅自外联、代发报价或介绍信 |
| 由 CEO 验证、谈判、决定是否继续 | 承诺成交、提供法律意见、宣称「已合规」 |
| 词元 / 模型 API 可作为**相邻撮合品类**（见第 6 节） | 假装已有对外下单平台或已成交案例 |

## 3. 智算供给指什么

不是「有个机房」这么笼统，而是对方能拿出来、能交付的智能计算能力，至少要说清：

- 卡型与可上架数量、能训还是能推  
- 机房位置与网络（出口带宽、时延、专线有无）  
- 交付周期、计费方式、大致价格区间（价格进敏感仓）  
- 数据驻留与出口管制等合规边界（只做公开信息提示，结论交给律师）

供给侧典型对象：国内智算中心、GPU/NPU 云与 IDC、服务器与集成商、有出海意愿的算力运营方。只在国内卖词元调用、背后没有可调度算力、也不愿意对接海外需求的，不视为本项目主供给。

需求侧典型对象：海外模型公司、区域云与 AI 应用商、需要训练或推理容量的企业、东南亚等地的数据中心租户。

## 4. 怎么做（业务流程）

```
发现供给 → 公开资料建档 → 真实性/完整性检查
发现需求 → 澄清规格/规模/价格/时间/地区/网络/合规
匹配（规则 + 人工）→ 解释匹配与不匹配原因
生成商务澄清清单 → CEO 跟进验证 → 记录结果
（脱敏案例可进研究库；联系人/报价/合同只进 B/99）
```

当前资产（截至 2026-11-12）：供应公开档原有 7 条，交流会 11 家供应线索建档进行中；需求公开档 9 条、脱敏匹配样例 3 组、内部澄清清单 3 份、本地 Matching MVP（不是对外网站）。对外自我介绍仍是草稿，须 CEO 另批后才能使用。

## 5. 收费模式（2026-11-12 CEO 锁定）

原则：撮合成功才收介绍费；不托管资金、不代收租金或词元调用费；不套用在线租赁平台 20%–25% 的平台抽成。

**主收费：成功介绍费**

- 向谁收：由**供给方**支付，需方看到的价格不加价（对标数据中心转介习惯）。  
- 计费基数：合同**首年应付总额**。算力 = 卡型 × 单价 × 时长（及合同期内承诺量）；词元 = 年承诺额或合同约定的调用额。  
- 分档（下限，可往上谈，不默认往下）：
  - 首年应付总额 **不满 100 万美元：不低于 10%**
  - 首年应付总额 **满 100 万美元：不低于 8%**
- 门槛说明：当前项目尚无自有成交价；100 万美元分界是依据 2026-11-05 公开云价目（证据 B-E22 Runpod、B-E23 Lambda）估算的集群年包租量级（约 32 张 H100 或约 24 张 H200 的公开标价年包）所作的**临时门槛**，待自有成交后再校准。公开标价不是本项目成交价。  
- 触发：双方签署正式合同，或发生首笔付款（以较早者为准）。  
- 窗口：经我方介绍后 **12 个月内**成交，均计入。  
- 结算：一次性，或随供给方回款分期；具体支付条款个案写进介绍协议。

**辅收费：项目顾问费**

- 适用：只要档案、匹配报告和澄清清单，暂不牵线介绍。  
- 与介绍费关系：若后续谈成，顾问费可抵对应介绍费。  
- 金额：按项目议，不设对外统一价目；未谈成也不假装「免费一定介绍成功」。

对外口径：在无书面介绍协议前，只说「个案商议、尚无统一公开价目」，**不在首轮口头报出分档数字**。分档仅作内部报价锚。

仍缺（须 CEO 后续拍板，不阻塞内部建档）：介绍协议合同模板、收款主体。

## 6. 词元 API 怎么放

可以做撮合，不可以自己变成 Token 工厂。把国内已有的模型 API / 词元供给，对接海外或跨境推理需求，流程、收费逻辑与算力撮合同一套，标的从「卡时」改为「调用量或年承诺额」。

跨境交词元比交算力更敏感（模型授权、数据出境、是否被认定为变相绕开算力管制），须律师意见，不能当成已经可卖的现成产品。故为**相邻品类**，不取代「智算供给出海」主线。

## 7. 帮双方做什么

- **供给方**：把可交付规格说清楚；找到配得上的海外或跨境需求；提前去掉明显不匹配或不建议硬配的单；由 CEO 安排介绍与跟进。  
- **需求方**：按规格、区域、网络、数据驻留出短名单；写清为什么配或不配、还要问什么；不把材料说成现成订单。  
- **双方**：合同、报价、履约由双方直接谈；我们不代签、不代收、不承诺成交。

## 8. 和同行比，我们站在哪

- 词元工厂 / 模型 API 聚合商：卖自己的产品，既是选手也是裁判。我们不自营供给。  
- Runpod、Vast、TensorDock 等在线租赁平台：按小时零售，抽成高，较少做跨境企业单和合规澄清。  
- 数据中心转介：模式近，但主做机柜与电，不是 GPU 规格 + 中国供给出海 + 管制提示。  

可对外说的优势（须属实）：专注中国供给对海外需求；匹配必须解释原因；合规只提示、不装已经过关。  

不可对外说：已有成交案例、已上线撮合平台、已铺开供应网络、价格一定更低。当前优势是方法，不是已验证的成交规模。

1. 将本文作为内部定稿，同步项目主文档与对外话术草稿（话术仍须 CEO 再批才能口述或外发）。  
2. 把 2026-11-11 前后交流会上拍摄的 11 家公司，按海报口径做成供应侧线索档（公开字段，不写未核实联系方式）。  
3. 请 CEO 点 1–2 家（优先有可调度算力或明确提到出海者：天顿、登甲、点动、硅基流动、华胜天成等）做人工验证；开口用已批准话术。  
4. 验证结果回填档案；联系人、报价、意向只进 B/99。  
5. 收费数字若再改，只改本文第 5 节，不另起一套模式；自有成交出现后优先复盘 100 万美元门槛。
