- **已建条数**：18（SUP-20261102-001～007；**本轮新增 SUP-20261112-001～011**，交流会 11 家公开线索，未外联、未人工验证）
- **材料能支撑的上限**：原有约 7 家（阿里云、腾讯、华为、中国移动、中国电信、中国联通、Aolani）+ 本轮交流会 11 家公开档。11 家均为线索级，联系人一律「暂无」，无成交价。
- **主要缺口类型**（沿用并补充）：
  1. 经核实的可售闲置容量表、卡型库存与联系人仍缺（需 Arthur 人工验证）
  2. 区域 GPU 云除 Aolani 外的具名主体：本轮补了国内交流会供给，但海外节点城市仍少
  3. 运营商及上市主体海外节点、SKU、公开价目仍缺系统采集
  4. 词元/模型 API 与可调度算力须继续分标；只卖词元且无出海意愿者主线优先级低
- **达标**：已远超供应侧 ≥5；质量上仍是公开线索，不是已验证供给。
