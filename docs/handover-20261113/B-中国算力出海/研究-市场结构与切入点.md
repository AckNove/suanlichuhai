# 研究：中国算力出海 — 市场结构、供需与切入点

> 状态：**已完成初版真实检索**（非法律意见；非已验证商业计划）  
> 获取时间：2026-11-02（Asia/Shanghai）

## 1. 市场结构（如何理解「出海」）

实务上至少有两类模式（**【事实】** 法律评述归纳，中伦 2026-07-10）：

1. **境内部署、跨境交付**：境内 GPU/智算，通过 API/Token 等向境外客户售卖推理或算力时段。  
2. **境外部署、境外销售**：在东南亚、中东、南美等设主体/合作部署集群，本地售卖。  

证据：B-E01。

延伸业态：**Token 出海**（境内或境外模型推理按 Token 计费跨境交付）— 金杜等律师文有讨论；本次作线索，**【待律师核验】** 不作为合规结论。

另有观察：**中国 AI 公司赴海外数据中心租用/远程使用先进 NVIDIA 算力**，以应对对华先进芯片出口限制（媒体报道）。证据 B-E02、B-E03。  
→ 这对项目的含义是双向的：既有「中国需求去海外找算力」，也有「中国供给如何合规服务海外/跨境」。

## 2. 海外潜在需求（公开信息）

**【事实】东南亚成为中国相关算力需求与投资热点叙述的核心区域。**  
- Business Times（2025-05-09）：中国企业在东南亚加租 AI 基础设施；提及新加坡、马来西亚、印尼，并延伸越南、泰国；中国客户对马来/印尼 AI 数据中心有 **5–7 年** 容量预订意向（顾问引述）。证据 B-E04。  
- CNBC（2026-08-19）：报道中国相关方经泰国、马来西亚、日本等远程使用 NVIDIA 算力；并引 DC Byte：马/印/泰规划中的 100MW+ 数据中心 **31** 座对比当前 **2** 座。证据 B-E03。  

**【事实】中国信通院《算力中心服务商分析报告》指出东南亚、中东、非洲等为服务商海外布局关注区域；并提及数据本地化与地缘带来不确定性。** 证据 B-E05。

**【推断】中东（数据本地化+上云）、拉美等亦被高盛等机构叙述为中国云厂商潜在建站方向。** 高盛页面本次抓取 **403 失败** → 相关「700 亿美元」等数字 **【缺失/未写入证据表】**，避免转述未打开页。

**【假设】中小海外模型团队、区域 ISV、本地化推理需求更可能成为初期撮合对象，而非直接撮合中美超大云之间的交易。** 待商务验证。

## 3. 供应侧情况

**【事实】中国智算供给规模快速扩大（国内底座）。** 信通院：2025-06 底机架 1085 万、智能算力 788EFlops（FP16）。证据 B-E06（与 A-E13 同源）。  

**【事实】运营商与互联网大厂在国内建万卡级智算、海外云节点/合资亦有公开叙述**（信通院报告对移动/电信/联通及阿里云等有描述）。证据 B-E06。  

**【推断】可出海「产品化」的供给可能包括：** 闲置时段推理 API、国产算力堆栈出口、第三方 IDC/算力运营的跨境套餐、整机柜集成交付。  
**【缺失】本阶段未建立经核实的供应商联系人与可售容量表。**

出口管制与芯片来源决定可售对象：含美国技术成分的 GPU 集群在第三国部署/向特定主体提供，可能触发 EAR/FDPR 等问题（中伦提示）。证据 B-E01。

## 5. 竞争格局（公开层）

**【事实】中国头部云/互联网（阿里云、腾讯、华为等）通过合资与租赁深化东南亚存在。** BT。证据 B-E04。  
**【事实】区域云与 GPU 云（报道中如 Aolani 等）承接远程训练需求。** CNBC。证据 B-E03。  
**【推断】撮合型创业公司的竞争者包括：线下经纪人、数据中心中介、云厂商销售、咨询公司。** 差异化应在「结构化匹配 + 合规清单 + 证据化供应画像」，而非拼广告。

**【缺失】未做系统竞品官网功能对比表。**

## 6. 主要障碍

1. **美出口管制**：物理芯片对华限制；远程访问漏洞可能被立法填补（House 已过 RASA、Senate 未过等报道）。B-E03。  
2. **中国技术出口管理趋严信号**：商务部 2026-10-16 就《禁止出口限制出口技术目录》修订征求意见，拟增列 AI 大模型、智能体、算力集群等相关技术；同时对开源、境外自建自营算力中心等设便利措施叙述。B-E08。**（征求意见/临时登记阶段，正式实施以官方后续公告为准）**  
3. **数据跨境与本地化**：越南等本地存储要求；马/印尼等监管机制（信通院）。B-E05。  
4. **东道国产能政策**：马来西亚放缓数据中心扩张的报道（Reuters 搜索命中；本次正文未成功打开则标待核验）。B-E09。  
5. **电力、土地、人才、信任与合同执行**。  
6. **平台无系统 ACL**：产品侧须自建隔离，否则商务数据有泄露流程风险。

## 7. 潜在切入点（【假设】+【推断】，待验证）

按「低资本、可控合规、可人工闭环」排序：

1. **合规敏感的匹配情报服务**：帮国内中小算力运营识别「能/不能接」的海外需求类型，输出澄清清单（不碰灰市代采芯片）。  
2. **推理/Token 跨境的供需对接**：聚焦非训练、可计量、合同短的订单（法律路径需律师）。  
3. **东南亚本地合规算力（非先进受限 SKU）与国产栈** 的区域客户撮合。  
4. **不要一上来做资金托管或自营超大集群**（与控成本、无云服务器约束一致）。

验收切入点的方法：Arthur 完成 ≥3 次真实通话，记录「需求澄清字段缺失率」与「匹配理由是否被对方认可」。
