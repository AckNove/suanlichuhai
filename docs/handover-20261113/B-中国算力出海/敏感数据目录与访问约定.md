## 2. 字段清单：敏感 vs 公开

### 2.1 必须进敏感仓（禁止进共享知识库 / 算力之王AK群 / 共享 memory / Notion 公开页）

| 类别 | 字段示例 | 建议文件命名 |
|------|----------|--------------|
| 联系人 | 姓名、职务、手机、邮箱、IM、名片 | `SUP-…_contacts.md` / `DEM-…_contacts.md` |
| 报价 | 单价、总价、折扣、有效期、付款条件、报价单附件 | `SUP/DEM-…_quote-YYYYMMDD.md` |
| 合同 | 合同全文、编号、签章扫描件、对账 | `CONTRACT-…` |
| 商务沟通原文 | 邮件/微信/通话纪要含可识别信息 | `COMM-…-YYYYMMDD.md` |
| 撮合结果涉密部分 | 双方未公开的成交意向、排他条款、介绍信草稿 | `MATCH-…_sensitive.md` |

公开档案（`01`–`03`）中上述字段只写：**「见敏感仓：文件名」**，不写具体值。

### 2.2 可进公开工作区 / 可共享研究（仍禁止编造）

| 类别 | 字段示例 | 存放 |
|------|----------|------|
| 主体公开信息 | 公司名、官网、公开报道、机房城市（公开资料） | `01`/`02` + registry |
| 能力参数（公开或已授权披露） | GPU 型号与规模区间、交付形态、公开合规声明 | `01`/`02` |
| 需求公开描述 | 用途、规格区间、区域、状态（线索级） | `02` |
| 匹配解释（脱敏） | 配对理由、差距、风险（不含联系方式/报价） | `03` |
| 澄清清单（脱敏） | 阻塞项清单、下次动作（无电话邮箱） | `04` |
| 市场与竞争 | 公开来源市场结构、竞品、合规研究 | `05` 或共享研究区 |

## 4. 操作闸门

1. **禁止编造**供应商/客户；无可靠来源不建档。  
2. **入库**：公开字段 → registry / 模板；敏感字段 → 仅 `99`，公开侧只留指针。  
3. **跨项目**：只传市场结构、合规、公开竞品；不传客户名单、报价、撮合细节。  
4. **外发**（介绍、报价、合同、对客消息）：必须经 **Arthur 确认** 后方可发出；总协调与出海侧均不得自行外发。  
5. **日志**：`04/_跟进日志.md` 仅脱敏；含联系方式的原文进 `99`。  
6. **后续本地/Git**（需本地环境）：敏感目录加入 ignore 或独立私仓；不得进公开研究仓。
