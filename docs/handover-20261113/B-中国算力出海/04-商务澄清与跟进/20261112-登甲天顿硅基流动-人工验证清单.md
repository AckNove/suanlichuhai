## 三家通用（每家都要问清）

1. 现在能交付的卡型、能训还是能推、可上架数量（不要营销口径里的「千卡」「万 P」）。  
2. 机房城市、是否自有或合营、新客户从下单到上架要多久。  
3. 网络：出口带宽、到主要海外城市时延、有无专线；海外节点是已开通可售，还是规划/宣传。  
4. 计费方式（按需 / 包月包年 / 承诺量）和最小起订；价格数字记入敏感仓，不写进公开档。  
5. 能不能、愿不愿意对接海外或跨境需求；签约主体是谁。  
6. 数据驻留和出口管制他们自己怎么划分边界；我们只记录对方陈述，不作合规结论。  
7. 是否接受由供给方支付成功介绍费、比例个案商议（首轮不报 10%/8%）。

## 1. 登甲智能（SUP-20261112-010）

公开已看到：广州琶洲；官网同时有 GPU 卡时租赁页和出海方案页；称按需/包月/包年，从单卡到「千卡集群」；出海页自称覆盖亚太、欧洲、北美，并称约 70% 为海外客户；公司新闻称通过信通院「可信 Token 云」评估（原榜本轮未打开）。以上均为公司自述或单方新闻，须当面核对。

**必须问清（阻塞）**

1. 当前可售的具体 GPU/NPU 型号、数量、能训还是能推；「千卡集群」是现网库存还是上限宣传。  
2. 机房在哪些城市；海外亚太/欧/美节点能否给新客户开通，各在哪座城市，还是只能跨境 API。  
3. 「约 70% 海外客户」如何统计、能否在不泄密前提下说明客户类型或区域分布，不能把官网数字当已验证业绩。  
4. 信通院「可信 Token 云」证书能否出示或提供可核验的原榜出处。  
5. 这次愿意优先对接的是 GPU 租赁，还是词元 API，还是两条都可以；若做词元跨境，须另走律师意见。

**重要但非阻塞**

1. 最小起租、交付周期（官网称 1 小时起、按需分钟级，须确认是否适用于出海单）。  
2. 结算币种（出海页称支持人民币与美元）和签约主体全称。  
3. DengCloud 只给自用还是也可给被介绍的客户用。

开口时不要复述「70% 海外客户」或「全国首批认证」，改问对方能否证明。

## 2. 天顿数据（SUP-20261112-009）

公开已看到：深圳天顿数据，粤港湾智算（**01396.HK**，不是 02139.HK）间接全资子公司；定位智算建设运营商；平台公开名是 **「量子湃」**（不要说成「量子湾」）；报道称可调度 GPU/CPU/NPU 等并支持按量、包年包月、Spot；母公司愿景为拓展全球 AIDC。精确容量、展板「100+ API」和具体海外节点，已打开材料里未交叉到可引用数字。

**必须问清（阻塞）**

1. 现在真正可售的卡型、数量、能训还是能推；量子湃调度的是自有机时，还是第三方资源池。  
2. 可售机房在哪些城市（河套是总部所在，不等于机房清单）。  
3. 全球 AIDC 是已有可售海外节点，还是集团愿景；若有节点，列出国家和城市。  
4. 海外或跨境客户由哪家主体签约：天顿，还是粤港湾智算，还是其他。  
5. 展板「100+ API」是否属实、是否对外可售；若只做算力、不做词元，当场划清。

**重要但非阻塞**

1. 按量 / 包年包月 / Spot 对外部客户是否都开放，最小起订和上架周期。  
2. 与母公司在销售、结算上的分工。  
3. 有无已公开、可核验的在服项目类型（不要追问未公开客户名单）。

开口时用对代码 01396.HK 和名称「量子湃」，避免说错。

## 3. 硅基流动（SUP-20261112-001）

公开已看到：北京硅基流动；主业是把异构算力做成词元服务，同时有专属实例、本地部署、算力联合运营；国际站 siliconflow.com 官网称 2025-06 上线；适配 NVIDIA、AMD 及昇腾、沐曦、摩尔线程等，称支持超 170 款模型。港交所申报里的海外经营数字仅为申报自述，不要当已核实业绩引用。词元跨境比交算力更敏感，**须律师意见后才能深谈跨境交付**。

**必须问清（阻塞）**

1. 除词元 API 外，专属实例和算力联合运营现在能否给新的海外或跨境客户预留可调度算力；卡型、位置、可预留规模、上架周期。  
2. 国际站实际开通的区域和数据驻留地；海外客户是调中国境内算力，还是已有境外部署。  
3. 他们是否已自行做过词元/模型 API 跨境的法律评估；我们不做合规结论，也不在律师意见前把跨境词元当成可卖现货。  
4. 愿不愿意通过介绍对接海外需求，还是只接受直销。  
5. 这次优先可谈的是词元调用、专属实例，还是联合运营机时。

**重要但非阻塞**

1. 无服务器词元与专属实例的计费和最小起订（数字进敏感仓）。  
2. 国产卡与 NVIDIA/AMD 在对外可售上的边界，对方如何对客表述。  
3. 国际站与国内站在型号、价格、合同主体上的差别。

开口时不要引用申报文件中的海外营收或客户数字；只问现在能否接、在哪交、以什么形态交。
