## 2. 三条业务主线（优先级固定）

### A. 中国智算供给出海（第一优先级）
服务中国智算中心、GPU 云服务商、算力运营商，帮助其开发海外/跨境客户。我方负责：海外市场研究、潜在客户发现、需求分析、GPU 资源寻源、供应商核验、需求与算力匹配、商务引荐、交易协调、项目跟进。

### B. 外数中算与跨境 AI 计算（第二优先级）
研究海外数据、模型推理、AI 工作负载进入中国境内处理的商业机会。**只做研究与合规路径梳理；未经专业法律审核前，不得对外承诺合法、合规或可执行。** 必须逐案研究：客户国家/地区、数据来源地、数据进入中国路径、计算地点、数据类型、是否涉及个人信息或重要数据、处理方式、结果交付方式、是否涉及技术出口/跨境数据传输/许可、客户是否愿意使用境内算力。

### C. 全球算力采购与资源配置（第三优先级）
逐步建立全球供应商数据库，为全球客户提供 GPU 采购、寻源、方案比较、持续采购管理。目标市场全球，不预先限定东南亚。

## 3. 我们卖什么（不是卖 GPU）

**需求方购买：** 需求分析 → 算力规格定义 → 全球资源寻源 → 供应商核验 → 采购方案比较 → 风险识别 → 商务协调 → 持续采购管理。
**供给方购买：** 海外市场研究 → 客户开发 → 合格采购需求筛选 → 商机引入 → 商务协调 → 持续渠道合作。

供需两侧必须是**两套不同的产品说明与商务方案**。任何材料不得把「赚信息差 / 收撮合费 / 抽成」直接讲给双边客户听；开口只讲对方能得到什么。

## 4. 收费原则（重要：不得写死费率）

- 采用灵活收费：客户采购顾问费、供应商海外市场拓展服务费、项目寻源服务费、成功介绍费、交易协调费、长期采购管理费。
- **历史 10%/8% 介绍费方案只是内部历史锚，不是当前强制最低费率，严禁在系统/合同/话术中写死。** 具体项目按服务价值、成交规模、交易风险、工作量、客户接受度单独商议，逐案由 CEO 审批。
- 若供需双方都付费，必须**事前书面披露**，避免利益冲突。
- 初期尽量让客户与实际算力供应商直接签算力合同、直接结算；**我方不托管客户采购资金**。
- 收费口径：首轮不报价；对方追问或进入介绍协议阶段时才说明「成功后书面约定、个案商议」。

## 5. 明确不做（红线）

自营 GPU 机房；自购 GPU 库存；Token 工厂或模型 API 零售；未获授权的芯片或算力交易；违规规避出口管制；客户资金托管；需方价格上加价；未经批准的跨境数据处理；提供法律意见或宣称「已合规」。

## 8. 线索分级（所有研究/数据必须标注）

`公开线索` → `推断需求` → `潜在机会` → `已核实需求` → `已合格商机`
- 公开线索：仅公开信息，无一手核实。
- 推断需求：由公开信号推断，未证实。
- 潜在机会：有较明确信号，需接触确认。
- 已核实需求：有 CEO/授权人一手访谈或书面确认。
- 已合格商机：完成资格核验 + 有决策人 + 预算/时间窗 + 可签约路径。
**禁止**把公开线索自动升级为合格客户/供应商。
