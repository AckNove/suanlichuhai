# CEO 审批矩阵 · 权限与留痕

> 版本：v1.0　｜　日期：2026-11-16　｜　状态：内部草案，待 CEO 审批
> 适用范围：所有 AI Agent、Skills 与人类协作者的对外动作。本文与 `PROJECT_BRIEF.md` 第 6 节一致；冲突时以 PROJECT_BRIEF 为准。
> 核心原则：**AI 生产建议与材料，人做承诺与签名。**

---

## 1. 审批等级定义

| 等级 | 名称 | 含义 | 谁可批 |
|------|------|------|--------|
| A0 | 自主 | AI 可独立执行，事后备案 | AI 岗位自主 |
| A1 | 备案 | 执行前告知 AI 项目总负责人，5 分钟内无异议即可执行 | AI 项目总负责人 |
| A2 | CEO 批准 | 必须 CEO 明确同意后才可执行 | CEO |
| A3 | CEO + 外部意见 | CEO 批准且需律师/会计等专业意见 | CEO + 外部专业方 |

**默认规则**：凡未在本文列明的事项，一律按 **A2（CEO 批准）** 处理，不得默认自主。

## 3. 自主（A0）与备案（A1）事项清单

### 3.1 A0：AI 可自主

| 事项 | 边界 |
|------|------|
| 公开信息检索与研究 | 不登录、不绕过访问控制、不爬取个人数据 |
| 内部文档撰写与修改（本人负责目录） | 不跨目录、不改他人文件 |
| 本地系统开发与测试 | 不部署到公网、不改生产配置 |
| 数据整理、去重、格式化 | 敏感数据须脱敏后处理 |
| 本地 Git 提交（开发分支） | 由 Lead 统一执行，Teammate 不提交（见 PROJECT_BRIEF 第 14 节） |
| 内部报告与摘要生成 | 明确标注事实/判断/假设 |

### 3.2 A1：备案即可

| 事项 | 备案对象 | 边界 |
|------|----------|------|
| 新建内部研究档案 | AI 项目总负责人 | 不含真实联系人 |
| 更新线索状态（LEAD→RESEARCHED） | AI 项目总负责人 | 不得跳级 |
| 生成内部会议议程草稿 | AI 项目总负责人 | 不得直接发送 |
| 修改 SOP 与模板 | AI 项目总负责人 | 涉及权限的改动升为 A2 |
| 内部数据备份 | AI 项目总负责人 | 备份不得含未脱敏敏感数据入公开库 |

## 4. 审批流程与时限

### 4.1 标准流程

```
发起（填写审批单）
  → 自检（必填项、风险标注、替代方案）
    → AI 项目总负责人审核（1 个工作日内）
      → CEO 审批（按 SLA）
        → 执行（仅限批准范围）
          → 留痕（审批单 + 执行记录 + 结果）
```

### 4.2 审批单必填字段

| 字段 | 说明 |
|------|------|
| 事项编号 | 对应矩阵编号（如 A-01） |
| 对象 | 客户/供应商/渠道（脱敏编号） |
| 内容全文 | 不得写「见附件」而不附 |
| 目的与预期结果 | 一句话 |
| 风险提示 | 至少 1 条最坏情况 |
| 替代方案 | 至少 1 个 |
| 有效期 | 批准的有效时间窗（默认 5 个工作日） |
| 发起人与日期 | 可追溯 |

### 4.3 时限与升级

| 情形 | 处理 |
|------|------|
| CEO 超时未批（>SLA） | 商务运营岗每日提醒一次；超过 5 个工作日标记 `CEO_PENDING` 并列入周会 |
| CEO 驳回 | 记录驳回原因；同一事项 7 日内不得重复提交（除非有实质变化） |
| 紧急事项 | 允许先口头批准后 24 小时内补书面留痕；口头批准仅限 CEO |
| 越权执行 | 立即停止、上报、写事故记录；重复发生则收紧该 Agent 权限（A-14） |

## 5. 留痕与审计

| 留痕类型 | 存放 | 保留期 | 谁可查 |
|----------|------|--------|--------|
| 审批单 | 内部审批记录（系统 `approvals` 表或 `docs/06_operations/` 归档） | 长期 | CEO、AI 总负责人 |
| 外联记录 | `project_activities` | 长期 | CEO、AI 总负责人 |
| 报价与合同 | `private/`（不入公开仓库） | 长期 | 仅 CEO |
| 收款记录 | 财务/敏感库 | 依法定期限 | CEO、会计 |
| 审计日志 | `audit_logs` | 长期 | CEO、AI 总负责人 |
| 系统变更 | 版本记录 | 长期 | AI 总负责人 |

**审计抽查**：AI 项目总负责人每周抽查 ≥5 条近期外联/材料，确认均有对应审批记录；无审批记录即视为违规。

## 6. 违规处理

| 级别 | 行为 | 处理 |
|------|------|------|
| L1 轻微 | 材料未按格式、字段缺失 | 退回重做，记录 |
| L2 一般 | 未经 A1 备案执行 A1 事项 | 警告 + 补备案 + 复盘 |
| L3 严重 | 未经 A2 执行外联/报价/对外发布 | 立即停止该 Agent 对外能力，CEO 复盘 |
| L4 红线 | 擅自签约、收款、承诺资源、数据出境、规避管制 | 全面停止该 Agent 权限，事件记录，必要时法律评估 |

**红线行为不适用「先做后补」**，一次即触发权限收紧。

## 附录 A　典型场景审批走查

| 场景 | 涉及条目 | 正确做法 | 常见错误 |
|------|----------|----------|----------|
| 客户在通话中要求「先给个大概价格」 | A-02 报价 | 记录需求，说明「价格需内部评估后书面回复」；24 小时内提交报价审批 | 当场给区间、给「参考价」 |
| 供应商要求「独家代理」 | A-04 介绍协议 + A-15 资源承诺 | 不签排他；如客户坚持，CEO 决定并写明期限与退出条件 | 口头答应「先做再说」 |
| 记者/自媒体询问公司情况 | A-18 媒体 | 转 CEO；不即兴回答 | 「随便聊聊」导致表述被引用 |
| 想订阅一个付费数据工具（月费 500 元） | A-11 采购付费服务 | 提交用途、替代方案、预算来源 | 直接刷卡后补流程 |
| 客户要求把训练数据发到国内算力节点 | A-12 数据出境 | 先走跨境筛查（CB 表），律师意见后再答复 | 「技术上可以」被理解为合规承诺 |
| 渠道伙伴要求先介绍客户再补协议 | A-04 + A-05 | 先签 NDA 与介绍协议框架，再披露需求要点 | 先给客户名单 |
| 员工想用公司账号注册开源项目/申请 GitHub 组织 | A-10 GitHub 权限 | 说明用途与权限范围，最小授权 | 给管理员权限 |
| 客户要求开具「合规证明」 | A-08 法律意见 + A-13 对外材料 | 明确拒开；可提供「按流程筛查的记录」 | 出具带公司章的说明 |

## 附录 B　授权与委托规则

| 情形 | 规则 |
|------|------|
| CEO 不在（≤3 天） | A1 事项照常；A2 事项由 AI 项目总负责人汇总，CEO 回来后一次性批；紧急事项按 D3（若批准）处理 |
| CEO 不在（>3 天） | 指定临时授权人，书面列明可批范围；A3 与红线事项一律不授权 |
| 员工休假 | 其审批角色由上一级代行，须在审批单注明「代行」 |
| 外部顾问 | 只能提供意见，不得代行审批 |
| AI Agent | 无审批权；只能生成审批包与提醒；权限变更走 A-14 |
| 转授权 | 未经 CEO 书面同意不得转授 |

**原则**：授权是「范围 + 期限 + 留痕」三件套，缺一不可；口头授权无效（紧急通道除外，须 24 小时内补书面）。

## 附录 D　审批 SLA 与超时看板

| 事项等级 | 发起后 SLA | 超时动作 | 看板字段 |
|----------|------------|----------|----------|
| A0 | 无需审批 | — | 不记录 |
| A1 | 24 小时内备案 | 系统提醒，不阻断 | 备案时间 |
| A2 | 2 个工作日 | 升级提醒 CEO；第 3 个工作日仍无响应则该事项默认「不批准」 | 提交时间/审批时间/时长 |
| A3 | 5 个工作日（外部意见不计入） | CEO 说明原因并给新期限 | 同上 + 外部意见编号 |

**看板规则**：① 所有 A2/A3 事项必须进入看板，口头申请不进入；② 超时率按月统计，目标 <10%（假设）；③ 「默认不批准」不等于拒绝，可补充材料重新提交；④ 同一事项不得拆分成多个更小事项以规避审批（拆单视为 L3 违规）。

## 附录 E　常见问题（内部答疑）

| 问题 | 回答 |
|------|------|
| 客户很急，能不能先打电话再补审批？ | 外联内容可以先口头沟通，但不得作出任何报价、承诺、身份越界表述；事后 1 个工作日内补 A-01 备案，内容必须与口头一致。 |
| 审批被拒，能不能找另一位批准人？ | 不能。批准权唯一；A2 只有 CEO，A3 必须含外部意见。 |
| 同一个模板发给 10 个客户，要批 10 次吗？ | 首次 100% 审批；同模板可申请季度备案，但客户名称与具体数字须填入后自行核对。 |
| 我能不能代表公司签一个「意向书」？ | 不能。任何带公司名义的书面文件（含 LOI、MOU）按 A-05 处理，须 CEO 批准。 |
| AI Agent 自动发出的邮件算谁的？ | 未经 A-01 且未由人点击发送的，一律视为越权，按 L3 处理；日志留痕。 |
| 审批记录能不能只留微信聊天？ | 不能。微信可作为补充证据，正式留痕须在审批单中。 |
