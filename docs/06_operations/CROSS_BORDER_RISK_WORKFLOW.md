# 跨境风险筛查工作流（重点：B 线「外数中算」）

> 版本：v1.0　｜　日期：2026-11-16　｜　状态：内部草案，待 CEO 审批；**须经律师复核后方可作为工作底稿使用**
> 适用范围：所有涉及跨境元素的项目（客户在境外、数据来源在境外、计算地点在境内、结果交付到境外、或任一环节涉及受控物项/技术）。
> 核心原则：**筛查是流程门槛，不是法律结论。任何「能不能做」的判断，必须由律师书面确认；本工作流只能标记「红线/待确认/可继续研究」。**
> 免责声明：本文档为内部风险管理工具，不构成法律意见，不得作为对客户的合规承诺或对外材料使用。

## 1. 适用范围与角色

| 项 | 内容 |
|----|------|
| 适用项目 | A 线（供给出海）涉及跨境服务/合同；B 线（外数中算）全部；C 线（全球采购）涉及跨境支付与转售 |
| 不适用 | 纯境内、无境外主体参与、无数据跨境的普通咨询 |

| 留痕 | 每单一份《跨境筛查表》，编号 `CB-YYYYMMDD-NNN`，存入 `private/` |

## 2. 十二步筛查流程（总览）

| 步 | 检查项 | 关键问题 | 输出 | 信息来源类型 | 待律师确认点 |
|----|--------|----------|------|--------------|--------------|
| S1 | 客户国家/地区 | 客户注册地、实际经营地、最终用户所在地、是否受制裁/管制地区 | 国家清单（≥3 个维度） | 客户自述（待核实）+ 公开登记 | 该国是否受中国/联合国/美欧制裁或出口限制 |
| S2 | 数据来源地 | 数据最初从哪来、经哪些国家中转、存储在哪 | 数据流向图 | 客户自述 + 合同/架构图 | 中转地是否引入额外法域义务 |
| S3 | 数据类型 | 个人信息？重要数据？一般数据？模型权重？源代码？ | 分类结论（附依据） | 客户提供的数据清单 + 我方识别 | 是否构成「重要数据」、是否含敏感个人信息 |
| S4 | 出境/入境判定 | 数据是否离开来源国、是否进入中国、是否再出境 | 是/否/待确认 | 技术架构 + 合同 | 远程访问是否视为「出境」 |
| S5 | 适用法域 | 中国（PIPL/数据安全法/网安法/数据出境规定）+ 来源国法 + 客户所在国法 + 第三国法 | 法域清单 | 官方法规原文（以最新版为准） | 各法域的具体义务、豁免、处罚 |
| S6 | 出口管制与制裁 | 是否涉及受控芯片、技术、软件、服务；是否涉及美方管制物项/技术 | 是否触发 | 官方清单 + 律师意见 | 物项分类（ECCN 等）、视同出口、再出口 |
| S7 | 计算地点 | 国内 IDC？境内云？境外节点？混合？ | 架构方案 | 供应商自述（待核验） | 跨境调度是否构成「技术出口」 |
| S8 | 结果交付 | 结果以什么形式交付（推理结果/权重/日志/报告） | 交付物清单 | 客户需求 + 合同 | 交付物是否含受控技术或个人信息 |
| S9 | 许可与资质 | 是否需要安全评估、标准合同、认证、出口许可 | 必备清单 | 官方指南 | 具体路径与时限 |
| S10 | 合同条款 | 数据处理协议、责任分配、终止权、审计权、合规陈述 | 条款清单 | 律师模板 | 条款有效性与可执行性 |
| S11 | 人工升级 | 是否出现红线或不确定 | 升级决定 | 内部规则 | — |
| S12 | 律师出具意见 | 书面意见与有效期 | 意见书编号 | 律师 | 全部法律结论 |

**执行顺序规则**：S6（出口管制）与 S11（红线）为**前置硬门**——任何一步触发红线，立即停止后续步骤并上报 CEO，不再继续推进。

## 3. 筛查表（模板字段）

| 字段 | 必填 | 说明 |
|------|------|------|
| 编号 / 日期 / 执行人 | 是 | `CB-YYYYMMDD-NNN` |
| 客户名称（脱敏编号） | 是 | 真实名入敏感库 |
| 客户国家/地区（注册地/经营地/最终用户） | 是 | 三个维度分开写 |
| 数据来源地/中转地/存储地 | 是 | 画流向图 |
| 数据类型 | 是 | 个人信息（是否敏感）/重要数据/一般数据/模型权重/源代码/日志 |
| 是否出境、是否入境、是否再出境 | 是 | 三问三答，不确定写「待确认」 |
| 适用法域 | 是 | 逐条列法规名称与版本 |
| 出口管制判断 | 是 | 涉及物项、ECCN（如已知）、判断依据 |
| 计算地点 | 是 | 具体机房/云区域 |
| 交付物形式 | 是 | 清单 |
| 结论 | 是 | 红（停止）/黄（待律师）/绿（可继续研究）三选一 |
| 升级记录 | 是 | 升级给谁、何时、结论 |
| 律师意见编号 | 条件必填 | 黄色/红色必填 |
| 复核人签字 | 是 | AI 项目总负责人 |

**结论含义**

| 结论 | 含义 | 允许动作 |
|------|------|----------|
| 红 | 触发红线，明确不做或须律师+CEO 双重批准前不得接触 | 停止，记录，上报 |
| 黄 | 存在不确定性，需律师书面意见 | 可做研究与内部讨论，**不得外联、不得处理真实数据** |
| 绿 | 初步判断无明显红线，仍待律师确认关键点 | 可继续研究，进入正式合规审查 |

> 注意：「绿」不等于「合规」。任何对外承诺必须等律师意见落地。

## 4. 决策树（文字版）

```
Q1 客户是否位于受制裁/出口管制高风险国家或地区？
 ├─ 是 → 【红线 R-01】停止
 └─ 否 → Q2

Q2 是否涉及受控芯片/技术/软件/服务的跨境提供（含远程访问、云服务、技术文档）？
 ├─ 是 → Q3
 └─ 否 → Q5

Q3 是否可能构成规避出口管制（拆分交易、第三方转运、隐瞒最终用户、不记录用途）？
 ├─ 是 → 【红线 R-02】停止
 └─ 否 → Q4

Q4 是否已取得出口许可或属于明确许可例外（须律师书面确认）？
 ├─ 是 → Q5
 └─ 否/不确定 → 【黄】律师意见，未出具前不得推进

Q5 是否涉及数据跨境（出境或入境）？
 ├─ 否 → Q9
 └─ 是 → Q6

Q6 数据是否含个人信息 / 重要数据 / 敏感个人信息？
 ├─ 是 → Q7
 └─ 否（一般数据）→ Q8

Q7 是否已完成中国数据出境安全评估 / 标准合同备案 / 认证（按适用路径）？
 ├─ 是 → Q8
 └─ 否/不确定 → 【黄或红】律师判断；未完成前不得处理真实数据

Q8 数据来源国/客户所在国是否禁止该数据出境或要求本地化？
 ├─ 是 → 【红线 R-03】停止
 └─ 否 → Q9

Q9 计算地点是否在境内且结果交付境外？
 ├─ 是 → Q10
 └─ 否 → Q11

Q10 结果是否含受控技术、模型权重、原始数据或可识别个人信息？
 ├─ 是 → 【黄】律师意见 + 合同条款设计
 └─ 否 → 可继续研究（仍需合同审查）

Q11 是否涉及第三国中转（数据或算力经由第三国）？
 ├─ 是 → 回到 Q5 逐法域重审
 └─ 否 → 可继续研究
```

## 5. 必须停止的红线情形（R 清单）

| 编号 | 红线情形 | 处理 |
|------|----------|------|
| R-01 | 客户/最终用户位于受制裁或明确禁止交易的国家/地区/实体清单 | 立即停止，不接触、不报价、记录上报 CEO |
| R-02 | 任何形式的规避出口管制设计（拆分交易、第三方转运、隐瞒最终用户、伪造用途） | 立即停止，记录，必要时法律评估 |
| R-03 | 数据来源国法律明确禁止出境，或要求强制本地化而我们无法满足 | 停止推进，告知客户无法承接 |
| R-04 | 客户拒绝说明数据类型、数据来源或最终用途 | 停止，不得「先跑起来再补」 |
| R-05 | 客户要求我方提供「合规承诺」「保证合法」的书面保证 | 拒绝出具，转律师；不得以公司名义担保 |
| R-06 | 涉及军事用途、监控用途、大规模人脸/生物特征处理（无合法依据） | 停止，需律师与 CEO 双重评估 |
| R-07 | 涉及未成年人数据、医疗健康数据、金融账户数据等敏感个人信息且无合法处理基础 | 停止 |
| R-08 | 客户要求将算力/模型用于生成违法内容或攻击性用途 | 停止 |
| R-09 | 我方无法核验供应商真实计算地点（可能实际在受管制区域） | 暂停，核验后再判 |
| R-10 | 款项需经非同名账户/第三方代付/现金，或客户拒绝提供交易背景 | 停止 |

> 红线判断执行人无权自行放宽；放宽须 CEO + 律师书面同意，并记录理由。

## 6. 法域清单（信息来源类型与待确认标注）

| 法域/主题 | 相关规则（示例） | 信息类型 | 状态 |
|-----------|------------------|----------|------|
| 中国—个人信息出境 | 《个人信息保护法》第 38–39 条及配套规定 | 法规原文 | 待律师确认适用路径 |
| 中国—数据出境安全评估 | 《数据出境安全评估办法》 | 法规原文 | 待律师确认触发条件 |
| 中国—数据跨境流动便利化 | 《促进和规范数据跨境流动规定》 | 法规原文 | 待律师确认豁免情形 |
| 中国—重要数据 | 《数据安全法》及重要数据目录（行业目录待查） | 法规原文 | **待确认**：是否已有适用目录 |
| 中国—网络安全 | 《网络安全法》相关条款 | 法规原文 | 待律师确认 |
| 中国—出口管制 | 《出口管制法》《两用物项出口管制条例》 | 法规原文 | 待律师确认物项范围 |
| 美国—AI 芯片/技术出口 | BIS 相关规则（近年多次调整，含 AI Diffusion 类规则及其后续变化） | 官方公告，**处于变动中** | **待律师确认当前有效版本**；不得引用过期条款 |
| 美国—制裁 | OFAC/商务部实体清单 | 官方清单 | 需逐案筛查，清单实时变动 |
| 欧盟—数据保护 | GDPR 跨境传输机制 | 法规原文 | 待当地律师确认 |
| 欧盟—AI | EU AI Act（分阶段生效） | 法规原文 | 待当地律师确认适用范围 |
| 其他 | 客户所在国数据本地化/内容审查要求 | 各国法规 | 逐案**待确认** |

**纪律**：以上仅为「需要查什么」的索引，不是结论。引用任何条款前必须核对**最新官方文本**与发布日期；不得使用记忆中的旧版本作为依据。

## 7. 升级路径

| 级别 | 触发 | 升级对象 | 时限 |

| E1 | 结论为黄 | AI 项目总负责人复核 | 1 个工作日 |
